对 CoastMAS 全系统执行一次“专业桌面 GIS / 科研工作台视觉系统重构”。

这是视觉与样式重构，不是业务架构重构。

参考当前 GeoAI 专业软件的视觉成熟度、信息密度和桌面工作台感，
但不要机械复制其品牌、颜色和具体页面。

目标：

让 CoastMAS 从目前偏“响应式 Web 管理后台”的视觉效果，
升级为：

专业 GIS
+
科研分析软件
+
空间规划工作台
+
桌面级数据分析软件

的视觉风格。

==================================================
一、最高优先级约束：不要改变现有布局和业务
==================================================

本任务原则：

“重构视觉，不重构布局。”

禁止修改：

1. V3 一级导航信息架构；
2. 页面路由；
3. API；
4. 数据结构；
5. 业务流程；
6. Assessment / Simulation / Planning / Comparison 四类任务；
7. 各任务八步；
8. 左侧导航、任务左栏、中央工作区、右侧步骤区、底部Dock的基本布局关系；
9. 已有按钮含义和业务动作；
10. 页面已有功能；
11. 地图/表格/图表实际功能；
12. 权限逻辑；
13. Run状态逻辑。

允许修改：

- 全局颜色；
- 字体；
- 字号；
- 字重；

==================================================
二、不要再采用“移动端优先的响应式后台风格”
==================================================

CoastMAS 是专业科研/GIS桌面工作台。

视觉策略改为：

Desktop-first Adaptive Workbench

而不是：

Mobile-first Responsive Website。

主要目标分辨率：

1920×1080
2560×1440
1440×900
1366×768

在正常桌面宽度下：

- 左侧导航保持工具栏/工作台结构；
- 中央视图保持最大空间；
- 右侧流程保持垂直工具区；
- 底部Dock保持可调整；
- 不因为宽度轻微下降就把面板堆成网页卡片；
- 不把按钮自动变成多行大块；
- 不将专业表格转成卡片列表。

可以保持现有响应能力，
但桌面断点不得破坏GIS工作台布局。

如果当前CSS中存在导致桌面区域无必要堆叠、
控件被放大或面板变成卡片的mobile-first规则，
进行纠正。

==================================================
五、颜色系统重新设计
==================================================

当前 CoastMAS 青绿色使用面积过大、饱和度偏高，
导致页面更像后台管理系统。

保留 CoastMAS 品牌青绿色，
但将其从“大面积背景色”改成“强调色”。

建议：

应用背景：
接近浅灰/灰白的中性底色。

Panel：
白色或非常浅的冷灰。

二级Panel：
极浅灰绿色/灰蓝绿色。

边框：
低对比中性灰绿色。

主文字：
深灰黑，不使用纯黑。

辅助文字：
中灰。

Accent：
保留 CoastMAS teal，
主要用于：

- 当前选中；
- 主操作；
- 运行状态；
- 关键焦点；
- 当前步骤；
- active indicator。

不要在：

大面积侧栏背景
大量button
大量badge
每个标题

都使用高饱和 teal。

整个页面同时出现的强Accent面积必须受到控制。


==================================================
六、左侧主导航重新做视觉，不改菜单
==================================================

保留现有导航内容和宽度结构。

但改成专业软件导航。

要求：

1. 菜单高度约 32–36px；
2. 图标约 16px；
3. 字号约 13px；
4. 分组标题约 11–12px；
5. 分组标题使用弱化色；
6. menu item默认不使用大色块；
7. hover为轻微背景；
8. selected使用：
   - 细Accent竖线
   或
   - 浅Accent背景
   +
   - 强文字；
9. 不使用大面积高饱和青绿色selected块；
10. 分组之间用间距或极细分隔线；
11. 图标、文字严格对齐；
12. 收起状态仍保持可辨识。

要让左栏看起来像：

专业工具导航

而不是：

Web后台菜单。
