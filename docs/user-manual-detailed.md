## 1. 基本概念与通用操作

### 1.1 每种对象是什么意思

| 对象 | 含义与用途 |
|---|---|
| 项目 | 一组成员的工作空间，决定可访问哪些资源。 |
| 场景 | 研究范围、时期、目标、条件及所选数据／实体；本身不计算。 |
| 数据资产 | 实际文件及来源、变量、单位、时空范围等说明。 |
| 地理实体 | 有身份、几何和有效期的岸段、湿地、管理单元等；不是计算结果。 |
| 模型 | 具有明确输入、输出、参数及适用条件的计算组件。 |
| 工作流 | 将模型连接起来，并固定参数和数据版本的计算流程。 |
| 运行／任务 | 按一个固定配置提交的实际执行，具有排队、成功或失败等状态。 |
| 结果 | 发布后的不可变数值、图表、来源与运行清单。 |
| ID 与版本 vN | ID 区分资源，版本区分同一资源的历史状态。名称相同不等于同一资源。 |
| 科学预检 | 检查数据、单位、坐标、时间、权限、运行资格等；保存配置不等于通过预检。 |
| AOI／CRS | AOI 是研究区域；CRS 是坐标参考系。EPSG:4326 表示经纬度。 |
| NoData／null | 无效或未知值，与真实数值 0 不同。 |
| 校验摘要／SHA-256 | 内容指纹，用于检查文件或版本是否改变，不是质量评分。 |

普通链路为：**数据与实体 → 场景 → 工作流 → 预检 → 运行 → 结果**。时间适配、评价、优化表单可帮助生成固定配置，再接入同一运行链路。

### 1.2 登录、项目和导航

1. 在运行系统的电脑打开 <http://127.0.0.1:58000>，使用分配的邮箱和密码登录；文档不提供通用密码。
2. 顶部“当前项目”选择目标项目，再开始操作。看不到项目时请管理员检查成员权限、账号状态和项目归档状态。
3. 切换项目前保存内容。切换会重新加载主内容，未保存输入不能保证保留；刷新、重新登录或从系统管理返回后也应核对项目。
4. 左侧分组可独立折叠，系统记住偏好；折叠菜单不会清空主表单或停止运行。手机从菜单按钮打开抽屉，选链接后关闭，也可按 Esc 关闭。
5. 工作完成后先保存，再使用底部“退出登录”。系统管理员可见“系统管理”；项目角色不自动等于系统管理员。

现名“智能编排／综合评价／科研验证”对应原“智能规划／评价中心／科研评估”。页面内“提交科研评估”等业务按钮名称仍保留。

### 1.3 所有表格、表单共用规则

| 元素 | 如何使用 |
|---|---|
| 名称／编号链接 | 点击打开详情；普通文字格不可直接编辑，双击不是电子表格编辑。 |
| 查看／编辑／查看与运行 | 操作所在行资源。先核对行的名称、ID 和版本。 |
| 复选框 | 只选中用于比较，不自动运行、删除或授权；再点击表外操作按钮。 |
| 上一页／下一页 | 仅翻当前表；不同表各自分页。每页最多 50 条不是全库总数。 |
| 表头 | 没有排序控件时不能靠点击表头排序。 |
| 宽表 | 在表格内部横向滚动，手机左右滑动查看右侧列。 |
| 正在读取数据 | 等待请求，不代表无数据。 |
| 暂无记录／无匹配 | 核查项目、筛选和页码；可能只是当前页没有记录。 |
| 操作未完成 | 阅读红色错误消息、错误码和追踪编号，不能当作空表。 |
| 灰色按钮／控件 | 可能处于历史只读、处理期间、权限受限或前置条件未满足。 |
| 保存版本 | 保存配置并追加历史，不自动运行；历史结果仍引用旧版本。 |
| 归档 | 保留历史；已被其他资源引用时可能拒绝，不要删除血缘来规避。 |
| 完整契约／清单 | 点击折叠标题展开只读原文；不是编辑器。 |

Tab 可切换焦点。科学字段空白不是 0；未确定的单位、时期和基准不要猜填。界面未承诺离开页面自动保存。

## 2. 三个真实影像演示

选择项目“中国典型海岸真实影像演示”。

| 场景 | 影像日期 | 内容与含义 |
|---|---|---|
| 黄河口 | 2025-09-25 | 真彩色和 NDVI；近红外减红光除以两者之和，用于植被相关光谱分析。 |
| 胶州湾 | 2025-10-27 | 真彩色和 NDWI；绿光减近红外除以两者之和，不等于已经确认的水体分类。 |
| 长江口 | 2024-09-01、2025-09-06 | 两期影像及后期减前期 NDVI，不单独证明长期趋势或因果。 |

### 2.1 先查看已有成果

1. 场景空间 → 点击场景名称 → 打开场景工作台。
2. 在“场景影像”勾选“显示真实影像”。“影像与采集时间”切换已绑定影像；长江口可分别查看两期。
3. “影像透明度”越大越不透明，只改变显示，不改变反射率或计算。
4. “地图底图”选择 OpenStreetMap 或 NASA GIBS；NASA 的“底图影像日期”只选背景日期，不会改变研究数据采集日期。
5. 到结果中心点已有结果，核对“来源与复现”的场景、工作流版本，再读数值、地图和统计。
6. “下载完整结果”保存完整数值与来源；显示图不是原始分析文件。

NDVI／NDWI 固定色标 −1 至 1，变化为 −2 至 2，无数据透明。这些是局部窗口，不是全海岸覆盖。NASA 底图标称 250 米，放大不增加分辨率；底图不进入分析绑定。

### 2.2 重新运行

在已保存且无未保存修改的场景中，找到“运行场景 v…”：选择对应“执行工作流” → “预检所选工作流” → 通过后“执行所选工作流”。不确定对应流程时，从已有结果的工作流来源链接核对，不要只看相似名称。

等待任务成功，再“查看不可变结果”。修改研究范围或参数时，先复制场景／另存工作流副本并准备兼容数据，保留原演示。数据来源和科学限制见[真实影像说明](real-imagery-demos.md)。

## 3. 项目概览与资源目录

概览卡片“场景、模型、可执行模型、工作流、数据资产、结果版本”显示当前项目数量，点击进入对应目录。“可执行模型”不表示适用于所有场景。

“最近运行”表：**任务**可点击；**状态**是执行阶段；**进度**是已报告进度，不是准确剩余时间。提供方未配置时，已有规则模板仍可用。

场景、数据、模型、工作流共用“资源 · 第 N 页”表：

| 列 | 含义与操作 |
|---|---|
| 名称 | 点击进入详情，小字 ID 用于区分同名资源。 |
| 类型／格式 | 模型类别或数据格式摘要，不是下载按钮。 |
| 版本 | 当前列出版本；历史通过相应管理页读取。 |
| 状态 | 已停用、已验证、可执行、可查看等；验证与执行资格不同。 |

搜索务必区分：

- 模型：“搜索全部模型”可按名称／标识、能力、类型、启用状态过滤，点“搜索模型”生效。
- 数据：“搜索全部数据”可按名称／标识、类别、格式、CRS 过滤，点“搜索数据”生效。CRS 填实际标识如 `EPSG:32650`。
- 场景、工作流：“筛选本页”仅过滤当前页。无匹配时清空并翻页，不代表全项目没有。
- 清除搜索要清空输入／选“全部”，再执行搜索。“刷新”只重新读取当前条件。

详情中的资源说明、输入／输出、科学约束、时间范围和完整版本契约均用于阅读；要改内容请进入对应管理／编辑页。

## 4. 场景空间与工作台

入口：场景空间 → 新建场景，或场景名称 → 打开场景工作台。

| 字段／按钮 | 填法与用途 |
|---|---|
| 读取场景版本 | 填版本号读取历史；留空为当前。历史不是覆盖新版本的捷径。 |
| 场景名称 | 建议包含研究区、时期和任务。 |
| 管理目标 | 完整研究目标及限定条件，不是立即运行指令。 |
| 保存场景版本 | 追加保存；修改后必须保存才能使用新配置运行。 |
| 复制场景 | 创建独立标识的副本，不改变原历史。 |
| 实体类型 | 英文逗号分隔契约标识，如 `wetland,management_unit`，不是自由中文说明。 |
| 开始／结束时间 | 真实时期，带时区，例如 `2025-09-25T03:01:20Z`；瞬时采集不能虚构一天覆盖。 |
| 所需输出 | 英文逗号分隔模型支持的输出标识，不能任意造名称期待自动解释。 |

**画范围：**“开始绘制 AOI” → 依边界点击至少三个不同点 → “完成 AOI”。“撤销顶点”去掉最后一点，“取消绘制”放弃当前绘制。避免自交。也可上传 WGS84 GeoJSON 的 Polygon／MultiPolygon 或 Feature，最多 8 MB，经度在前、纬度在后。“AOI 坐标系”必须与坐标一致，改标签不等于重投影。

橙色 AOI、绿色实体、蓝色数据范围。背景最多显示前 500 个实体。地图可拖动平移、缩放。

**选版本：**在“选择地理实体／数据的精确版本”勾选条目并可翻页继续选择；展开“已选…版本”核查，“移除此…版本”仅取消引用。一个资源只能选择一个版本。明确选择数据后，工作流外部输入必须属于这个集合，否则阻断。

**情景条件／数据策略／质量要求：**按模型需要填写科学字段，编辑方法见第 20 节。基准海平面、垂向基准、人口假设、目标网格不能从别的模型随意照搬；新加字段也不意味着模型会使用它。

点击“检查场景与数据覆盖”只检查当前草稿，不保存或运行。修改后重新检查。

| 覆盖表列 | 含义 |
|---|---|
| 资源版本 | 本次检查对象的精确版本。 |
| 空间覆盖 | 数据范围与 AOI 相交比例；实体采用相交检查可能不显示比例，不是有效像元率。 |
| 时间覆盖 | 覆盖／不完整／未知；未知不能算通过。 |
| 状态 | COVERED 覆盖、PARTIAL 部分、OUTSIDE 范围外、UNKNOWN 未知；展开“覆盖检查说明”看原因。 |

保存后选择执行工作流，先“预检所选工作流”，再“执行所选工作流”。未保存、未选工作流、预检失败或提交中会限制操作。“查看项目结果”只打开目录，不代表当前任务已完成。

## 5. 数据目录、上传和预览

新增“业务资料检查”入口：用于读取本机资料检查报告，查看原栅格单位、网格、NoData、类别频数、大文件限制与模型用途。它不上传原数据，也不等于已完成业务计算。具体报告位置及操作见[真实业务接入](business-data-integration.md)。

点击“选择业务资料检查报告”并选取 JSON 文件后，下方才显示两张表。它不是原始影像上传入口。栅格表中“文件”是相对路径与体积，“网格与坐标”是尺寸／波段／投影，“统计范围”区分全图与采样，“值与类别数量”显示原始值及像元频数，“待处理条件”列出尚缺依据。负数与零不能直接当缺测；频数不是面积。输入路径关键词筛选整个报告，每页20条，用表格底部翻页；修改筛选会回到第一页。“原始检查项与指纹”可展开查看完整CRS、变换参数和SHA256。

模型表显示包名／版本、聚类或回归用途及许可证；展开“模型声明与指纹”查看依赖和原声明。显示“不可执行”表示尚无经验证运行接入，不能据此认为模型已安装。来源与单位的“用户声明”与文件自身元数据分别显示。读取无效报告会显示错误并清除上一份结果，重新选择正确报告即可；刷新页面后需重新选择。

数据目录 → 上传数据 → 选择“数据文件” → 填说明与变量 → “上传并检查数据”。单文件最多 64 MiB。超限应准备有科学依据的数据分区，不要更改扩展名冒充格式。

| 字段 | 填写规则 |
|---|---|
| 数据名称 | 可识别名称，不能代替来源。 |
| 数据来源 | 提供方、产品／调查批次、采集依据，不填密钥。 |
| 许可证 | 真实使用许可，不知道先核实。 |
| 数据类别 | raster 栅格、vector 矢量、table 表格、json 结构化 JSON。 |
| 文件格式 | 按实际选 GeoTIFF／COG／GeoJSON／Shapefile／GeoPackage／CSV／NetCDF／JSON；Shapefile 用配套文件 ZIP。 |
| crs／vertical_datum | 真实水平坐标系／垂向基准；无信息保持未设置，不猜值。 |
| spatial_extent | 与实际文件一致的空间范围声明，不是想研究的区域；结构按适用数据契约。 |
| time_start／time_end | 实际带时区观测覆盖；瞬时观测不伪装成连续时期。 |
| time_resolution | 实际时间分辨率／统计支撑，不规则观测不捏造固定频率。 |
| 添加数据变量 | 每个绑定变量分别说明名字、单位、量纲等，详见第 20 节。 |

数据管理页的操作：

| 控件／按钮 | 作用 |
|---|---|
| 查看数据版本 | 当前版或历史版；历史只读。 |
| 下载此版本原始文件 | 下载选中版本的实际文件，不是预览截图。 |
| 读取实际文件预览 | 读取有界样本和测量记录，不修改数据。 |
| 保存数据修订 | 保存元数据新版本，保留原文件、撤销先前质量资格；换文件应另行上传。 |
| 重新检查并保存质量版本 | 重新核查实际文件并保存质量版本，元数据修改后需要此步骤。 |
| 归档数据 | 保留历史和文件；已引用时可能拒绝。 |

**预览表：**列名来自原文件，每行是一个样本记录。`null` 表示缺失，0 是真实零值。表格只读，不支持改单元格或粘贴多行；需改数据时修改原文件后再上传。非表格预览展开“文件预览内容”。预览不是全量下载，检查通过也不等于科学审批。

“此版本质量记录”展开看实际测量与声明来源；“已核实的评价来源／数据来源”可跳转固定来源版本，核查来历。

## 6. 外部数据源

入口：数据目录 → 外部数据源。只使用管理员批准的连接器，不是任意网址下载或 SQL 工具。

列表“名称”点击进入；“来源类型”表示 HTTP／数据库等，“版本”是声明版本。填“搜索数据源”后点“搜索”，清空再搜索恢复；底部翻页。

1. 点“登记数据源”，填“数据源名称”，选择“已批准的连接器”并核对配置版本。
2. 填输出数据的来源、许可证、格式、时空声明和变量。数据库只读导出 CSV，应选 table／CSV。
3. 点“保存数据源版本”：只保存声明，尚未取得文件。
4. 点“导入文件快照”，等待实际读取与检查，再“查看已导入数据”。
5. 同一次重复提交返回同一快照；需要新采集时先“准备下一次导入”，再导入。

历史声明通过“查看数据源版本”读取，历史只读；“归档数据源”受已导入快照的引用保护。无批准连接器或显示“当前不可用”时，请管理员按[配置说明](data-sources.md)处理，不能把密码粘进来源字段或临时改任意查询。

<a id="entities"></a>
## 7. 地理实体

左侧“实体目录”是选择列表：点击读取，“新建实体”打开新建表单；“读取版本”留空为当前，填版本号查看旧版。每页最多 50 个。

| 字段 | 含义／填法 |
|---|---|
| 实体名称 | 可读名称。 |
| 实体类型 | 岸段、湿地、地块、行政单元、管理单元、水体、保护区、自定义；岸段用线，面积对象用面。 |
| 管理单元标识 | 用于和结果输出对齐；管理单元类型必须提供，不能与实体自身 ID 混同。 |
| 源坐标系 | 几何真实二维 CRS，坐标 X/Y 顺序；不猜坐标系。 |
| 生效／失效时间 | 带时区，结束可留空；有效区间含开始不含结束。 |
| 几何文件 | 单个 GeoJSON Geometry／Feature，最多 8 MB；不能把多实体 FeatureCollection 隐式合并。 |

“保存实体版本”后检查成功提示与版本。修订未选新文件则保留原几何和属性。“版本来源与属性”展开可看原属性和摘要。

右侧“当前空间版本”地图始终展示当前空间查询结果，读取历史表单不会把它变成历史地图。目录按名称、地图按标识排序；同页对象不保证一一对应，地图也需翻页查看更多。

只有输出管理标识与场景选中实体的管理标识匹配，结果才可定位。上传几何不自动补写旧结果；未绑定时数表仍保留。

<a id="temporal"></a>
## 8. 时间适配

**用途：**依据真实观测时刻或区间，将时间尺度转换为目标时刻／窗口，保留单位和缺测含义。不是修改文件时间标签。

### 8.1 四组字段

| 分区／字段 | 含义与填法 |
|---|---|
| 来源与场景：沿用研究区的场景 | 选已有场景的区域；保存会创建独立场景并使用目标时间，原场景不变。 |
| 名称／数据来源／许可证 | 新适配数据的名称、实际观测来源和许可，不是底图来源。 |
| 物理变量 | 输入观测的明确变量名，须符合后续使用的科学含义。 |
| 输入单位／输出单位 | 例如 `degC` → `K` 或 `mm` → `m`，维度必须兼容；单位不填在数值格中。 |
| 统计含义 | 连续量／区间平均、总量／区间累计、瞬时量、类别；按观测真实含义选，不按想用的方法倒推。 |
| 适配方法 | 只显示适用于当前含义的方法，选择变化可能改变下方时间控件。 |
| 观测支撑 | 观测时刻或实际区间；某些方法强制支撑类型，只显示说明。 |
| 缺测策略 | “传播缺测”允许结果未知；“拒绝含缺测的计算”遇缺测阻断；均不自动补零。 |
| 目标时刻 | 最近观测／插值要计算的一个时刻。 |
| 目标开始／结束时间 | 平均、累计或极值所用的目标窗口。 |

### 8.2 方法选择

| 方法 | 何时用 | 不能这样用 |
|---|---|---|
| nearest 最近观测 | 从范围内取最近点观测；等距取较早值 | 不越出观测范围，不跳过缺测找别的点 |
| interpolation 线性插值 | 连续／瞬时量两相邻点之间估计 | 不外推、不插类别；相邻缺测不会被填补 |
| mean 时长加权平均 | 每条值代表一段时间平均，如各时段平均温度 | 不是对不等长区间简单算术平均；不允许区间重叠或空档 |
| sum 累计 | 每条是区间总量，如各段降水累计 | 每段只加一次，不把累计量当瞬时量，也不采用含偏移的单位换算 |
| min／max 极值 | 目标内实际观测支撑值的最小／最大 | 不证明未观测期间的连续极值 |

### 8.3 “时间观测”表怎样逐行填写

| 列／按钮 | 操作 |
|---|---|
| 观测时刻／区间开始 | 填带时区时间，如 `2025-01-01T00:00:00Z`；按时间顺序录入。 |
| 区间结束 | 区间模式才显示；写真实结束，不猜固定频率。 |
| 数值 | 只填数字，不带单位；留空表示缺测，0 要明确填 `0`。 |
| 删除观测 N | 删除这一行草稿，不是删除已保存数据资产。 |
| 添加观测 | 增加一条空行；每行都要按实际资料填完整时间。 |

完成后“保存时间适配工作流”，成功跳到已选场景的工作流页 → “科学预检” → “提交运行” → 结果。保存还会创建固定数据记录，不仅是保存表格截图。

### 8.4 可手算的完整练习

**仅在练习项目中录入，来源标记为教学合成数据，不能加进真实演示作为观测。** 选择一个已有场景作为区域，填写：

- 名称：温度时长加权练习；来源：教学合成数据；许可证：自建教学数据。
- 物理变量：`air_temperature`；输入单位：`degC`；输出单位：`K`。
- 统计含义：连续量／区间平均；方法：mean；支撑：实际区间；缺测策略：传播缺测。
- 目标开始：`2025-01-01T00:00:00Z`；目标结束：`2025-01-01T04:00:00Z`。

| 区间开始 | 区间结束 | 数值 |
|---|---|---|
| 2025-01-01T00:00:00Z | 2025-01-01T01:00:00Z | 10 |
| 2025-01-01T01:00:00Z | 2025-01-01T04:00:00Z | 20 |

保存、预检、运行后，预期为 `(10×1 + 20×3)÷4 = 17.5 ℃ = 290.65 K`，有效／使用观测数为 2／2。该基准已有自动化验证；本次文档更新没有向用户项目写入练习数据。项目没有兼容可信模型时会阻断，不能通过修改科学声明冒充兼容。

## 9. 智能编排

**用途：**从目标和已授权目录生成候选工作流；候选不自动执行，也不是任意自然语言问题都能解决。

1. “规划场景”选已保存的正确版本。
2. “管理目标”输入完整目标。可展开“确定性模板示例”使用页面已有模板，例如“可持续性评价：等权综合评价”，但必须具备实际所需模型和数据。
3. “允许必要时请求外部模型”决定是否授权使用配置的提供方。规则可解决时不调用；此处“外部模型”也可能由管理员配置为本机兼容服务。
4. 点“生成规划”，依次看“任务拆解”“数据与推荐依据”。超出模板时系统保留完整原文，不会忽略附加条件；有条件时可点“请求外部候选”。
5. 对有多个兼容候选的数据变量，在相应下拉框明确选版本，重新生成。默认“自动匹配；多个合格候选将阻断”不会替你任意挑选。
6. 缺失条件解决、候选有效后，“保存工作流”；之后还需到工作流页预检运行。

| 区域／内容 | 怎样理解和操作 |
|---|---|
| 任务拆解 | 看目标是否被正确解释，是否漏条件；输入改动后旧产物过期，需重新生成。 |
| 数据与推荐依据 | 看缺什么数据／约束，不要只看“推荐”二字。 |
| 候选流程 · 尚未执行 | 查看模型连接和输出，不是执行进度。 |
| 调用预算与真实账本 | 预留额度不是实际完成请求；点“刷新调用账本”读取真实记录。 |
| HTTP／错误／原始用量 | HTTP 未响应表示未收到响应；用量未报告保持未知，不能填 0。 |
| 规划产物与追踪标识 | 展开保存的候选、依据及追踪记录，便于问题排查。 |

提供方最多按本流程的预算请求，不等于允许无限重试。模型输出即使结构合法，仍需要审阅目标解释；未知模型、缺输出、数据科学约束错误会被拒绝。

## 10. 工作流编辑与运行

### 10.1 建立流程

工作流目录 → “新建工作流”；已有流程从详情点“编辑工作流／另存副本”。

| 控件 | 如何使用 |
|---|---|
| 工作流名称 | 便于区分目标与配置的名称。 |
| 场景类型 | 必须与要运行的场景／模型适用条件一致，不能为绕过预检任意更换。 |
| 模型工具箱 | 拖模型到画布，或点击添加；节点固定模型版本，不会自动升到新版。 |
| 输入／输出端口 | 从上游输出拖到下游输入。循环、同一输入多来源会被拒绝。 |
| 选择节点 | 在右侧／下方选择要编辑的节点，才能填它的参数和数据。 |
| 节点参数 | 按声明单位填数；必填参数不猜值，0 是有效数字；只有声明的默认值才自动填。 |
| 输入数据 · 端口名 [单位] | 未接上游时选择数据精确版本；“已连接上游节点”表示使用上游输出，不再同时绑定文件。 |
| 发布输出 · 端口名 | 勾选需作为工作流成果发布的输出，不是选中画布节点。 |
| 删除选中节点 | 删除节点及其连接、绑定与输出声明，操作前确认不是仅想取消选择。 |
| 删除连线 N | 删除相应连接；下游该输入可能需要重新绑定。 |

画布拖动节点只改变编辑视图，不改变计算语义。工作流不是只靠线条好看就能运行；输入单位、变量含义、时间和空间支撑必须匹配。

### 10.2 保存和校验

1. 在“草稿科学预检”选择“预检场景”。
2. 点“校验当前草稿”，逐条看节点／工作流、错误码和消息；节点会显示待预检、已验证或存在错误。
3. 修复后重新校验；更改草稿或场景使旧结果失效。
4. “保存工作流版本”生成新版本；“另存副本”生成新标识。允许保存科学尚不完整的草稿，不表示能运行。
5. 回详情页选“运行场景”，设置“随机种子”，点“科学预检”，通过后“提交运行”。更改场景或种子必须重新校验。

随机种子用于可复现的随机计算，不是重复次数。确定性模型可能不使用随机数，但清单仍保留种子。

“计算流程”图及“精确版本、参数和数据绑定”用于核查最终保存配置。“归档工作流”保留历史，被运行或评价记录引用时可能拒绝。目录加载达到 500 条上限会提示，未加载模型不会自动参与编辑。

## 11. 模型中心与静态拆解

### 11.1 目录与基本字段

模型中心 → “新增或导入模型”，或目录名称 → “管理模型版本”。检索方式见第 3 节。

| 字段 | 意义／填法 |
|---|---|
| 模型名称／展示名称 | 契约名称／面向阅读的名称；不会凭名称自动获得算法。 |
| 说明 | 方法、用途、条件和限制。 |
| 模型类型 | OPTIMIZATION 优化、STATISTICAL 统计、PROCESS 过程、MACHINE_LEARNING 机器学习、RASTER 栅格、GIS 地理处理、HYBRID 混合、EXTERNAL 外部；选择实际类别。 |
| 运行类型 | `metadata` 表示仅登记不执行；其他类型也必须有已批准、可信的运行实现。 |
| 许可证 | 实际模型／代码许可。 |
| 能力／科学领域 | 使用英文逗号分隔契约标签，不是输入自然语言就产生能力。 |
| 添加输入变量／输出变量 | 添加端口契约，逐字段见第 20 节。 |
| 添加参数 | 名称、单位、最小／最大值、默认值、必填；未知默认保留空，不猜 0。 |
| 科学适用范围 | 空间／时间尺度、几何类型、CRS、科学约束，详见第 20 节。 |
| 运行配置与文献 | 只填适用运行契约需要的配置及真实方法依据，不能将密钥写入。任意配置不等于安装新执行器。 |

### 11.2 文件、版本和状态

| 按钮／控件 | 作用 |
|---|---|
| 导入 JSON／YAML 模型文件 | 最大 256 KiB，填入声明表单；导入后仍需核查并保存，不是上传代码立即运行。 |
| 保存模型版本 | 创建／修订，科学契约修改会撤销原验证与执行资格。 |
| 查看模型版本 | 选历史只读；回当前最新版本编辑。 |
| 导出此版本 JSON／YAML | 导出当前选中的精确版本。 |
| 复制模型名称 → 复制最新模型 | 指定新名字复制最新模型，不是当前正在看的任意历史版本。 |
| 启用／停用模型 | 控制可用性，启用不代表科学验证或运行审批。 |
| 归档模型 | 保留历史；引用保护可能阻止归档。 |

非内置模型的可信运行审批、拆解候选审核注册完整闭环尚未完成。当前不能仅靠填这些表单把任何脚本变为可执行模型。

### 11.3 静态拆解

入口“静态拆解模型”。先填“待拆解模型名称”，再选方式：

| 方式 | 输入与含义 |
|---|---|
| Python 源文件 | 上传或粘贴代码，最大 256 KiB；只静态分析，不导入执行。 |
| 命令行参数 | 每行一个完整 argv 参数，首行为程序名；空行忽略。包含空格的一个参数仍放一行，不要按空格拆碎。 |
| 已声明组件／已有流程 | 上传含 components、dependencies 的实际声明 JSON；组件和依赖须有效、无环。 |
| 黑箱原子模型 | 保留整体，不猜内部算法或拆出虚构阶段。 |

点“生成拆解候选”，修改输入后旧候选隐藏，需要重新生成。“待审核拆解候选”的图只供查看；警告必须保留并审阅。

| “拆解组件”表列 | 意义 |
|---|---|
| 组件 | 标识及签名，定位原组件。 |
| 阶段 | 预处理、计算、后处理或验证职责。 |
| 输入／输出 | 已发现／声明的端口；“未声明”不等于无需数据。 |
| 保留原子性 | “是”表示不可据此次静态分析进一步拆开。 |

可下载候选用于审核；下载候选不等于保存可执行工作流。

## 12. 知识图谱

**用途：**浏览真实资源契约之间的关系，寻找可能连接的模型或数据。

1. 选择“中心节点”；“完整图谱”可能较大。
2. 选择“邻域深度”0–4 层，越大范围越广。
3. “关系类型”筛选某一类边；点图中节点查看详情。
4. “打开来源资源”查看模型／数据／场景／工作流，“以此节点为中心”继续探索。
5. 超过 300 节点时界面要求缩小邻域，关系表仍保留查询结果。

“关系与证据”表每页最多 100 条，**来源**是起点，**关系**说明联系，**目标**是终点，**依据**区分声明／候选／冲突。底部总数是当前筛选关系数，翻页看其余，不是模型总量。

| 关系 | 意义 |
|---|---|
| REQUIRES 需要 | 输入、条件或步骤所需对象 |
| PRODUCES 产生 | 模型输出或数据声明变量 |
| SUPPORTS 支持 | 声明的任务能力 |
| DEPENDS_ON 依赖 | 已保存工作流的步骤依赖 |
| MAPS_TO 映射到 | 数据类型／绑定映射 |
| VALID_FOR 适用于 | 声明的实体或场景类型 |
| INCOMPATIBLE_WITH 不兼容 | 明确的维度或语义冲突 |
| DERIVED_FROM 来源于 | 节点来自固定模型版本 |
| CAN_FOLLOW 候选下游 | 变量契约相符，仍需数据、CRS、基准、时间及资格预检 |

虚线候选边不是“已运行成功”。图谱表只读，不能在表格里改关系；修改需回来源资源并保存新版本。

## 13. 运行中心

“最近任务”表：**任务**点击进入；**状态**见下表；**进度**为已报告百分比；**执行尝试**为实际尝试计数，不是成功结果数量。页面没有全量分页控件时，不能将最近任务视为全部历史。

| 状态 | 含义与下一步 |
|---|---|
| QUEUED 排队中 | 已提交，等待执行；可按页面按钮取消。 |
| RUNNING 运行中 | 正在计算，可能需要等待；取消是请求，需执行端确认。 |
| SUCCEEDED 已成功 | 任务产物已发布；仍须检查科学输出和业务结果。 |
| FAILED 失败 | 看错误码、消息和运行快照，定位原因。 |
| CANCELLED 已取消 | 已结束取消，不代表产生有效成果。 |

“取消任务”变为“正在取消…”时，不要认为已经停止。“按原快照重试”仅在失败／取消等可用状态出现，仍用原输入版本，不能用于套用刚编辑的新参数；要用新配置，应从新工作流／场景重新提交。

`REMOTE_STATUS_UNKNOWN` 表示远端状态未知，重试会被禁用，避免重复远端执行；交维护人员核查，不要另建任务盲目重复。

“查看不可变结果”进入已发布产物；科研任务则进入科研报告。“运行快照与精确版本”展开查看冻结输入，报错时记录任务 ID、错误码、追踪编号、时间及所用版本。

对照页左右分别显示场景、工作流、时期、参数、来源和下载。**管理指标对照表**按节点、输出、变量、管理单元及指标对齐：

### 14.2 详情通用区域

- “下载完整结果”：保存完整产物；页面展示可能只显示样本或前 100 行。
- “实际计算耗时／实际执行节点／执行阶段 LLM 调用”：执行记录，不是规划调用预算；LLM 为 0 对确定性计算是正常的。
- “来源与复现”：工作流、场景、随机种子、软件版本、输入指纹；展开完整运行清单。核查时以精确版本为准。
- 遥感图保留固定色标，无数据透明；“栅格矩阵 N 行×M 列”指完整网格规模，下载可取完整值与 NoData。
- “原始输出”中的表列随模型变化，表格只读，不提供现场修正科研数值的功能。

### 14.3 管理结果与地理实体

| 表列／按钮 | 含义与操作 |
|---|---|
| 结果对象 | 本次输出对象；展开“对象与来源”看原记录。 |
| 管理单元 | 输出中的管理单元标识，不是地理实体自身 ID。 |
| 地理实体版本 | 与该次运行匹配的确切版本；“未绑定”不能猜位置。 |
| 指标与单位 | 原值和单位，可能有受淹面积、人口、分数、变化等。 |
| 定位… | 有可用绑定几何时联动地图；点地图对象也可联动表。 |
| 显示全部绑定实体 | 恢复显示所有已绑定对象。 |

绑定状态：BOUND 全部、PARTIAL 部分、UNBOUND 尚未绑定、NOT_APPLICABLE 无此语义。没有几何时保留数表，不虚构地图。

地图共用控件：“显示面图层”“显示边界与线图层”“显示点图层”控制显示；隐藏图层不会删除实体。底图、日期、影像透明度只影响查看，不影响原结果。

### 14.4 海岸筛查统计表

**管理单元**是统计对象；**受淹面积（m²）**为筛查面积；**估算人口（人）**依赖声明的人口分布假设；**未知面积（m²）**是 DEM 无效区域。顶部卡片与表中数值应按所显示范围理解。

展开“计算方法与假设原文”核查。这是地形连通筛查，不是水动力模拟；未知 DEM 区域不能算安全，也不能算已受淹。

### 14.5 单期／多期评价表

“评价管理单元”选全部或一个单元，“查看评价年份”切换年份。

- 所选年份表：**管理单元、年份、分数（1）、等级**；`1` 表示无量纲，不是“第一名”。等级来自本次框架，不是通用管理标准。
- 展开“完整时间序列表”：第一列年份，其余各列为对应单元分数；折线按实际年份间隔显示。
- 未声明年份不自动填当前年份；不同框架的分数不应直接比较。

### 14.6 时间适配结果

“物理变量”“计算值及单位”“适配方法”“有效／使用观测数”“目标时间（UTC）”“使用的源观测范围”“缺测策略”用于核查计算。结果未知可能是正确传播缺测，不等于程序漏算；极值只代表实际观测，不能解释为连续时段真实极值。

## 15. 综合评价与评价记录

**用途：**把多个有单位的指标按明确公式、方向、参考范围和权重转成可比较分数，再按固定配置运行。指标体系不是观测数据本身。

### 15.1 指标体系列表与新建

列表列为**名称、当前版本、操作**；“编辑与准备数据”打开该体系，“新建指标体系”开始创建；“查看评价记录”查看已冻结的评价配置，“查看评价结果”转到结果目录。列表底部翻页。

| 体系字段 | 填法 |
|---|---|
| 体系名称 | 能区分研究对象和评价方法的名称。 |
| 依据与适用范围 | 写理论、数据依据与适用对象，不只写“综合评价”。 |
| 空间评价单元 | 管理单元、行政单元、自定义多边形或网格，应与观测空间支撑一致。 |
| 示范体系（DEMO FRAMEWORK） | 仅用于明确示范性质；不能给正式体系勾选后当作已获科学认可。 |
| 共同权重方法 | 手工权重、等权、熵权（全时段共同估计）；同一体系各时期共享规则。 |

### 15.2 每个“指标 N”如何填写

点“添加指标”增加一组。标识由系统维护，用户填写下面内容。

| 字段／按钮 | 含义与要求 |
|---|---|
| 指标名称／分类 | 可读名称及实际分类；内置示范分类不是唯一理论。 |
| 输出单位 | 公式计算结果的单位；无量纲填 `1`，不要用“分”代替不明确的单位。 |
| 指标方向 | 越高越好／越低越好，决定归一化方向。 |
| 参考下界／上界 | 明确的固定归一化范围，上界大于下界；超范围会阻断，不自动剪到 0–1。 |
| 手工权重 | 仅手工方法填写非负值；允许个别 0，但总和必须大于 0。等权／熵权由计算产生。 |
| 指标公式 | 默认 `x` 表示直接使用对应列；支持受限算术、比较、where、sqrt、log、abs，不是 Python 编辑器。 |
| 公式输入 x 对应的数据列 | 填观测文件里的精确列名，不是指标中文显示名，也不是第几列。 |
| 添加公式输入 | 增加 `input2` 等别名并填真实列名，在公式中引用该别名。 |
| 移除输入 | 删除不用的映射；公式也要同步调整，不能留下未定义变量。最后一个输入不能移除。 |
| 删除指标 N | 从当前编辑体系移除该指标，不修改已经保存的历史评价。 |

例如原观测列叫 `coverage`，定义输出单位 `1`、公式 `x`，将 x 映射到 `coverage`；若真实值为比例且科学参考范围明确为 0–1，就填下界 0、上界 1。**百分数 30 与比例 0.30 不相同**，应先核对文件单位和数值，不按习惯猜。

输入先转换到基础单位：公式中的加减／比较常数应按基础单位理解；归一化边界按输出单位填写。温度、面积等不能直接套无量纲示例。

“分级阈值”控制 0–1 分数的等级边界，必须严格递增且位于 0 与 1 之间；等于阈值进入更高一级。页面默认 0.25、0.5、0.75 是可编辑设置，不是所有研究的通用标准。

### 15.3 保存、准备观测、生成方案

1. 填好全部指标后点“保存指标体系版本”。有未保存编辑时“准备固定版本输入”不可用。
2. 在“准备评价输入”搜索观测数据，点“搜索观测”。下拉选择实际观测文件，核对“观测版本”；手填的版本必须真实存在。
3. 所选文件须是经检查的 JSON 指标观测结构 `indicator_frame`。**不能把任意 CSV 改扩展名为 JSON 使用。** 文件中的实体标识、列定义、单位和时期须对齐。数据负责人可参照[评价说明](assessment-center.md)准备。
4. 点“准备固定版本输入”。系统读取真实文件、计算公式，保存带体系和观测来源的新数据；“查看实际文件与质量”可核对。
5. 在“生成评价工作流”选择“评价场景”和“评价方法”：加权综合评价或 TOPSIS（仅单期）。多期自动加入变化与趋势节点，不能使用无共同理想点定义的多期 TOPSIS。
6. 点“生成评价方案”，核查流程和缺失条件；成功后“保存评价记录与工作流”。

观测文件的 `unit_ids` 是按顺序排列的实体／单元标识，`columns` 定义列名与单位等，单期 `values` 为“单元×指标”矩阵；多期为“时期×单元×指标”，`years` 严格递增且与时期一一对应。此说明用于与数据负责人沟通，不意味着页面自动把任意表转换成该结构。

“查看指标体系版本”可读取历史；历史只读。修订不改变已准备输入。“归档指标体系”受来源引用保护。

### 15.4 评价记录两张表

记录目录：**名称、版本、操作**，“查看与运行”打开记录。它固定体系、数据、场景及工作流；修改条件应建立新方案和记录。

详情中点击体系／输入链接可看精确历史，“下载固定场景定义”保存场景原文。设置“随机种子” → “科学预检” → “提交评价运行”。“归档评价记录”保留配置与历史任务。

“匹配固定配置的实际运行”表：

| 列／按钮 | 意义 |
|---|---|
| 任务 | 点击任务详情。 |
| 状态 | 实际队列执行状态。 |
| 结果 | 有结果时“查看评价结果”；“尚无已发布结果”不等于数值 0。 |
| 刷新运行记录 | 重新读取匹配任务；上／下一页运行仅翻此表。 |

匹配按工作流、场景和输入版本，可能包含从工作流页提交的同配置任务，不能把所有行都解释为从这个按钮发起。

## 16. 空间优化

**用途：**在明确可加假设及硬约束下，从候选单元中选择一组使总收益最大。不是自动生成政策，也不从影像自动猜成本或收益。

目录“固定优化配置”表列为**名称、版本、操作**；“查看与运行”打开固定配置，“新建优化配置”录入新方案。

### 16.1 新建字段

| 字段 | 填法与科学含义 |
|---|---|
| 优化名称／基础场景 | 选固定场景版本；保存复制独立优化场景，不覆盖基础场景。场景可翻页选择。 |
| 数据来源标记 | 标明真实资料或教学合成等性质，不得将 SYNTHETIC 当作现场观测。 |
| 可加性与科学依据 | 说明收益、成本、生态成本、风险为何可按列求和，以及候选面积为什么互不重叠。 |
| 面积／收益／成本／生态成本／风险单位 | 每列明确单位，如面积 `m^2` 或 `ha`；无量纲为 `1` 并解释定义。不要填写系统不识别的自造单位。 |
| 预算上限 | 所选单元成本和不得超过该值，单位同成本列。 |
| 最低面积 | 所选面积和至少达到该值，单位同面积列。 |
| 生态成本／风险指标上限 | 对应列总和的最大允许值。风险是可加惩罚指标，不是可直接相加的概率。 |
| 计算时限（秒） | 当前允许 0.01–120 秒；到时不一定已有最优解。 |

每个候选单元包含：**候选标识、候选收益、候选成本、候选面积、候选生态成本、候选风险、允许选择**。

- 标识唯一；需要地图绑定时，应与所选场景的管理单元标识一致。
- 面积必须大于 0；成本及相关边界按校验要求非负，不能填 NaN、无穷或布尔值冒充数值。
- 取消“允许选择”是硬保护，即使收益很高也不能选。基础场景已有保护清单不会被此表取消。
- “添加候选单元”增加一组，“删除候选 N”移除草稿中的该组；当前最多 5000 单元。
- “载入合成示范”填的是教学／验证值，会影响当前草稿。正式研究应录入真实来源，不要把示范值混入三个影像场景。

### 16.2 保存与执行

“保存固定优化配置”冻结实际输入文件、数据、场景及工作流。详情可“查看固定输入文件”“查看固定场景原文”。设种子 → 科学预检 → 提交优化运行。变更条件须建新配置，不能覆盖已运行输入。“归档配置”保留历史。

“真实运行记录”表：**任务**打开运行，**运行状态**为执行状态，**操作**中的“查看优化结果”加载此行输出，“地图与完整结果”进入通用结果页；底部分页独立控制任务记录。

### 16.3 结果与两张结果表

| 优化状态 | 含义 |
|---|---|
| OPTIMAL | 求解器报告最优且经约束核验。 |
| INCUMBENT | 已有经核验可行解，但未证明最优；阅读相对间隙。 |
| INFEASIBLE | 约束下无可行方案，应审查资料／约束，不是“全都不选”。 |
| TIME_LIMIT | 达到时限，检查是否实际提供可行解。 |
| FAILED | 计算／核验失败，读取诊断。 |

任务“成功”表示报告发布，可能报告的是不可行问题。

| “硬约束”表列 | 含义 |
|---|---|
| 硬约束 | 本行核查哪条预算、面积、生态或风险条件。 |
| 方向 | 要求 ≤ 上限或 ≥ 下限。 |
| 边界／实际值 | 约束阈值与求解值；无可行值不是 0。 |
| 单位 | 本行报告单位；结果面积统一平方米，不要与输入公顷直接比较数字。 |
| 核验 | 满足／不满足／未获得可行解。 |

| “候选分配”表列 | 含义 |
|---|---|
| 候选标识 | 对应录入单元。 |
| 硬保护 | 允许／禁止选择。 |
| 分配 | 选中／未选／无分配；无分配表示没有可解释的分配解。 |
| 面积 m²／收益／成本 | 对应候选的实际值及指定单位，不是手工编辑格。 |

空间绑定状态只表示是否找到固定实体版本，不证明输入面积、经济收益或政策假设正确。

## 17. 协同方案

**用途：**记录各方目标、硬约束、意见及真实结果证据，进行版本比较和独立人工审核；不自动作出政策决定。

### 17.1 方案目录怎么操作

| 列 | 操作与含义 |
|---|---|
| 比较 | 勾选该行固定版本；翻页选择会保留，离开／更换项目不要假设永久保存。 |
| 方案／版本 | 名称和被比较的明确版本。 |
| 角色 | 作者的角色，不是你的当前权限。 |
| 状态 | 草稿、待人工审核、已人工审核、退回修订。 |
| 操作：查看 | 打开该方案详情，不是提交审核。 |

“比较所选版本（N）”在选中 1–20 份且未处理中时可用；超过 20 份需取消部分选择。“清除比较”清空选择和比较结果，不删除方案。分页只改变列表页，不等于清除跨页勾选。空表显示“暂无协同方案”，用“新建方案”录入，不需假数据填表。

### 17.2 新建与修订字段

| 字段／分组 | 填法 |
|---|---|
| 方案名称／依据与意见 | 明确方案内容、立场和事实依据。 |
| 固定场景 | 选择可访问的明确版本，可用场景分页寻找。 |
| 目标标识／目标名称／目标权重 | 标识区分目标；权重为非负相对权重，总和大于 0。“添加目标／删除目标”调整草稿目标组。 |
| 约束指标 | 稳定指标标识；不同方案只有同一指标才进行相应数值比较。 |
| 约束单位 | 明确且可识别，如 `m^2`；不能写模糊的“面积单位”。 |
| 约束下界／上界 | 至少填一个；空白表示无该边界，0 是实际边界，下界不能大于上界。 |
| 添加硬约束／删除约束 | 增减草稿约束组，不改已保存历史。 |
| 已有结果编号 | 可选，英文逗号分隔；从结果中心核对真实 ID，必须是本项目、同一固定场景的成功结果。 |
| 保存方案版本／取消编辑 | 前者追加保存；后者放弃当前编辑，不删除已有版本。 |

目标权重不会自动合成各方最终政策。硬约束冲突不能靠更高目标分数抵消。

### 17.3 审核、公开和意见

1. 作者在当前草稿／退回版本点击“提交人工审核”。
2. **另一位**有 MANAGER／ADMIN 权限的用户查看待审核版本，填写“人工审核意见”，点“记录审核完成”或“退回修订”。作者即使是全局管理员也不能自审。
3. 已审核版本可由有权限的管理者“向公众公开方案”；“撤回公开”取消公开状态。公开方案不会递归公开引用的私有数据或结果文件。
4. 作者“编辑为新版本”会回到草稿，清除旧审核结论并撤回公开；旧历史仍保留。
5. “查看 vN”读取历史，只读主体；“新增意见 → 记录意见”将意见绑定当前查看版本，旧意见不随新版本迁移，也不能覆盖编辑。

PUBLIC 只访问已公开或自己的方案及获准场景；VIEWER 只读。普通成员看不到审核按钮时，先核对角色、作者身份、当前版本和状态，不能只刷新期待权限出现。场景公开本身需有权限的既有管理接口，目前不在系统管理页提供单独按钮。

### 17.4 比较结果两张表

“方案版本比较”表：**方案／版本、固定场景、目标权重、依据、真实结果引用**。结果链接可进入原产物；查看不同场景时必须核对范围和时期。

“区间交集”表：**指标、统一单位、交集下界、交集上界**。例如同一指标一个方案要求 ≥10，另一方案要求 ≤20，交集是 10–20；若前者要求 ≥30，则无共同可行区间。该数字仅说明比较方法，不是实际政策阈值。

单位不兼容显示 `UNIT_MISMATCH`，无法有限换算为 `UNIT_CONVERSION_FAILED`，空交集为 `EMPTY_INTERVAL`；同时看各约束来源。未发现已录入区间冲突不代表整体政策可行，也不保证遗漏条件不存在。“与上一版本比较”用于当前方案的前后版本核查。

<a id="research"></a>
## 18. 科研验证

**用途：**比较规划方法生成的候选是否有效、用了多少实际请求及时间；本页不执行候选科学模型。

### 18.1 建立样例并提交

1. 选择“研究场景”，填写完整“研究目标”。
2. 勾选同一实验允许使用的候选模型和数据，固定准确版本。每个样例最多 12 个模型、64 份数据，界面各类列出前 500 项，没选的数据不会自动补入。
3. 点“加入固定样例”，核对已加入的目标和数量；“移除样例 N”只移除当前研究草稿样例。最多 20 个。
4. 勾选实验组：A 规则规划；B LLM 推荐；C LLM＋知识图谱＋约束。
5. 设置“重复次数”1–5。总试验＝样例数×实验组数×重复数，不得超过 100。
6. B/C 要实际调用时勾选“允许调用已配置的提供方”。不勾选／未配置时记录阻塞，不会偷偷替换成规则结果。每个 B/C 试验最多一次提供方请求。
7. 点“提交科研评估”，从“科研任务记录”表的任务链接看进度与报告。该表的状态、进度含义同普通任务，底部可翻页。

只有需要重复实验时才提高次数；预算和重复次数不等于更高质量。本机 Qwen 也需要正确配置，拒绝的候选保留证据，不应修改原报告把失败写成通过。

### 18.2 任务与报告状态

“报告生成状态”显示队列任务进度；可按按钮“取消科研任务”，取消请求需确认。“查看运行、取消与重试记录”跳任务详情。“冻结研究输入”可展开核查。

报告 `COMPLETE`＝全部试验完成评估，`PARTIAL`＝部分完成，`BLOCKED`＝全部阻塞。**任务成功、报告完整、候选有效是三件不同的事。** 科研成果 RAW 不等于科学已审批。

来源分别是 RULE 规则、LOCAL 本地提供方、EXTERNAL 外部提供方、MOCK 模拟协议、REPLAY 历史回放，不能混合宣传为真实模型表现。

### 18.3 “科研分组统计”逐列解释

| 列 | 含义／读法 |
|---|---|
| 实验／来源 | A/B/C 方法以及 RULE/LOCAL 等实际来源；同一方法不同来源分开统计。 |
| 已评估／总数 | 前者确实完成评估，后者包含阻塞与失败，不能删失败缩小分母。 |
| 阻塞／失败 | 没满足执行条件与已尝试但失败的数量，性质不同。 |
| 完成率 | 已评估数÷总试验数。 |
| 工作流有效率 | 科学有效的候选试验数÷已评估数；应同时看完成率。 |
| 约束违规率／观测数 | 只基于实际候选的检查，不把没有候选当成已审查候选。 |
| 人工修订次数／观测数 | 来自真实人工修订记录；当前无记录时“未观测”，不表示零次修订。 |
| 平均耗时（秒） | 已记录延迟统计；未知不补零，不等于整个平台端到端耗时。 |
| 实际请求 | 真实已发送尝试的记录，不是预留额度或计划次数。 |
| 提供方 token | 提供方返回的用量；未提供时保持未观测，不能按字数估算。 |

### 18.4 “逐项试验与证据”逐列解释

**样例／重复**定位输入和第几次；**实验／来源**标方法；**状态**为已评估、阻塞或失败；**存在候选**表示是否得到候选；**科学有效**是本次检查结论；**诊断**显示失败原因。“候选、用量与追踪”展开每项原始证据，“下载完整科研报告”保留全部 JSON。

当前真实本机 Qwen 已有一次固定样例 A/B/C 实验：A 有效，B/C 被科学检查拒绝。这证明真实链路工作，不证明模型质量达标或总体方法优劣。人工修订观测入口、完整错误注入／消融／性能及统一研究报告仍在研发。

## 19. 系统管理

只有系统管理员可见。该页管理账号、项目、角色和审计，不是模型执行审批或连接器密码配置界面。

### 19.1 创建、启停账号与密码

填“新账号邮箱”“初始密码”（12–256 字符）→“创建账号”。创建后还要分配项目角色，普通账号才可进入相应工作区。

| 账号表列／按钮 | 操作与影响 |
|---|---|
| 邮箱 | 下方小字是账号 ID，用于重置密码和设置项目成员；不要用邮箱代替 ID。 |
| 状态 | 已启用／已停用。 |
| 系统角色 | 系统管理员／普通账号，不是项目角色。 |
| 停用账号／启用账号 | 改账号可用性；停用后相关访问受限。 |
| 设为系统管理员／取消系统管理员 | 改全站管理权，确认操作对象后使用。 |
| 上／下一页账号 | 每页最多 50 个；不会改变其他表页码。 |

当前自己的启停／管理员切换按钮禁用，服务端还保护最后一个有效管理员。不是靠更换邮箱名称就能成为管理员。

重置密码：从账号表复制正确 ID → 填“重置密码的账号标识”和“新密码” → “重置密码并撤销旧会话”。用户须用新密码重新登录。不要在日常演示中用真实用户做停用／重置试验。

### 19.2 项目与历史记录

填“新项目名称”→“创建项目”。项目表：**项目**为名称与标识，**状态**为使用中／已归档，**操作**为归档／恢复。

归档从普通工作区隐藏整个项目，保留模型、数据、任务、结果、历史和权限。要撤销访问必须调整授权或停用账号，不能用归档代替撤权。恢复后应重新核对顶部项目。

### 19.3 项目成员与角色

先选“管理项目”，核对成员表的**成员邮箱、项目角色、账号状态**；再填“成员账号标识”，选择“项目角色”，点“保存成员角色”。已有成员会更新角色，不是创建另一份同名成员。

| 项目角色 | 用户应如何理解 |
|---|---|
| ADMIN 管理员 | 项目级管理角色，具体操作由服务端权限决定，不自动等于系统管理员。 |
| RESEARCHER 研究人员 | 参与有授权的科研编辑与运行。 |
| MANAGER 管理人员 | 包括协同管理／审核等授权操作，仍不能自审自己的方案。 |
| VIEWER 只读成员 | 查看获准资源，不用于写入／提交操作。 |
| PUBLIC 公开参与者 | 仅允许限定公开协同及自己的方案，不能据此访问所有私有资源。 |

这张表帮助理解角色，不能代替每个接口的具体授权。当前界面提供设置角色，**没有单独“删除成员”按钮**；严格撤权需求由管理员通过已有授权管理能力处理，不要把改成 VIEWER 当成彻底无访问。

### 19.4 审计记录表

| 列 | 意义 |
|---|---|
| 时间 | 操作记录时间，核对发生顺序。 |
| 操作 | 创建账号、设置角色、归档项目、修订资源等动作。 |
| 操作者 | 真实执行账号标识。 |
| 对象 | 被操作的资源／账号／项目。 |
| 变更记录 | 点“查看审计详情”展开完整记录。 |

用“上一页审计／下一页审计”翻页。审计表只读，不提供删除、改写日志或修改历史证据的按钮。

## 20. 科学字段填写字典

模型、数据及场景部分字段使用同一结构化编辑器。它可以输入复杂契约，但不会替你判断科学依据是否成立。

### 20.1 “类型、字段组、有序列表”怎样用

| 控件 | 使用方法 |
|---|---|
| 文字 | 普通说明、标准名、单位、CRS 或日期字符串。 |
| 数值 | 只填有限数字，不附单位；0 保持为 0，空白为未设置。 |
| 是／否 | 选明确布尔值；“未指定”不同于“否”。 |
| 有序列表 | “添加…项”增加元素，每项可再选类型；“移除第 N 项”删除指定元素，顺序有科学意义时不可随意交换。 |
| 字段组 | 输入字段名，点“添加…字段”，再设值及类型；“移除字段”删除此键，不是将值置零。 |
| 类型下拉 | 改类型会重新初始化该字段的值／列表／字段组；已有内容先核对，不能反复切换期望保留原值。 |
| 固定下拉选项 | 只能选择契约允许值；“请选择”仍为空，不能当作自动匹配。 |

新增字段名必须是契约认可的名字，不能重复；界面允许添加不等于任意字段都能被保存或用于计算。复杂输入不懂时，应从正确的既有资源或方法文件核查，不要试填直到不报错。

### 20.2 数据变量／模型输入输出逐字段解释

| 界面名（契约键） | 含义与例子 |
|---|---|
| 名称 name | 文件列或模型端口使用的名称；必须与实际绑定方式匹配。 |
| 标准变量名 standard_name | 跨模型识别同一科学量的标识；应沿用目标模型要求，不能把描述随意翻译成新标识。 |
| 说明 description | 该量如何观测／计算以及限制。 |
| 数据类型 data_type | raster 栅格、vector 矢量、table 表格、scalar 标量、array 数组、json 结构容器。 |
| 单位 unit | 如 `m`、`m^2`、`mm`、`degC`、`K`、`1`；使用兼容模型认可的单位。 |
| 量纲 dimension | 物理维度，例如长度 `[length]`、温度 `[temperature]`、无量纲 `dimensionless`；面积可表示为 `[length] ** 2`。不能仅因单位文字不同就判维度不同。 |
| 语义类型 semantic_type | continuous 连续量；categorical 类别；extensive 总量。类别不能插值，总量不能任意取平均。 |
| 空间支撑 spatial_support | 数值代表哪类空间对象，例如网格、管理单元；按模型真实契约填写，不能为匹配模型改写实际支撑。 |
| 时间支撑 temporal_support | 代表一个时刻、时间区间或模型规定支撑；需和数据实际时间含义一致。 |
| 聚合语义 aggregation_type | intensive 强度／平均量，extensive 总量，categorical 类别，instantaneous 瞬时量。 |
| 缺失值策略 nodata_policy | reject 遇缺失拒绝；mask 按适用模型掩膜；propagate 保留／传播未知。只有模型支持的方法才有效，不是任意填补工具。 |
| 必填 required | 是否必须有该输入；取消必填不能掩盖实际上必需的数据。 |

温度用 `degC` 不意味着量纲也写 `degC`；名称、标准名、单位、量纲各司其职。JSON 结构容器可能声明单位 `1`，但内部每列的真实物理单位仍需保留，不能据外层单位把所有数值当成无量纲。

### 20.3 模型参数、尺度和约束

| 字段 | 意义 |
|---|---|
| 参数名称／说明 | 在模型中实际使用的参数名及科学含义。 |
| 参数单位 | 数值的单位；范围和默认值都按此单位。 |
| 最小值／最大值 | 允许范围；未知不等于 0。 |
| 默认值 | 仅存在真实默认时填写，否则留空要求运行者提供。 |
| 空间尺度／时间尺度 | minimum、maximum、unit 表示可用范围及单位，不是地图缩放级别。 |
| supported_geometry | 模型真正支持的几何类型列表。 |
| supported_crs | 模型真正支持的 CRS 列表；列进去不会自动安装转换方法。 |
| 约束 field | 被检查的契约字段。 |
| 约束 operator | eq 等于、ne 不等于、ge 大于等于、le 小于等于、in 属于集合、required 必须提供。 |
| 约束 value／description | 对照值及依据；值类型需符合所用运算符，例如集合检查使用适合的列表。 |
| references | 可核查的方法／文献依据，不是任意运行命令。 |

### 20.4 常见场景科学条件

| 字段 | 解释 |
|---|---|
| sea_level_baseline_m 基准海平面 | 适用筛查模型的基准值，须与高程垂向基准兼容。 |
| vertical_datum 垂向基准 | 真实高程参考，不能用单位换算代替基准转换。 |
| coastal_seeds 海岸连通起点 | 栅格行、列起点列表，不是经纬度；只按相应模型要求填写。 |
| population_distribution 人口空间分布假设 | 估算人口所用假设，必须有说明，不能当作观测事实。 |
| target_grid 目标栅格 | 字段组含 crs、transform、width、height；仿射六参数与行列数来自真实网格元数据，不凭地图大小猜。 |
| data_label 数据性质 | 标明真实、合成等来源性质，不能通过改标签把示范数据变为观测。 |
| period_policy 时期比较规则 | 多期如何共享参考条件，按模型契约填写。 |
| method_scope 方法适用范围 | 方法在哪些条件下有效及其限制。 |

## 21. 常见问题与当前边界

| 现象 | 先检查与处理 |
|---|---|
| 项目／资源不见了 | 核对顶部项目、页码、筛选、账号权限、启停及归档状态。场景／工作流搜索只筛当前页。 |
| 按钮灰色 | 看是否历史只读、未保存修改、未选场景／数据、预检失败、正在提交或权限不够；不要跳过校验。 |
| 保存版本冲突 | 重新加载最新版本，比较后再保存；不要强行覆盖他人修改。 |
| 文件解析失败 | 核对真实格式、大小、配套文件、编码和结构；不能只改扩展名。 |
| 单位／变量不匹配 | 对照第 20 节和目标模型声明；名称相近不等于物理量相同。 |
| CRS／垂向基准／网格错误 | 核对实际元数据。换标签不等于重投影；单位换算不等于高程基准变换。 |
| 时间覆盖不足 | 使用真正覆盖目标的观测，或有依据地调整研究时期；不虚构时间范围。 |
| 场景选了数据仍运行失败 | 工作流每份外部输入的精确版本都须在场景选定集合，且契约兼容。 |
| 归档被拒绝 | 检查引用与历史依赖，保留科学来源；使用新版本／新配置继续工作。 |
| 没有在线底图 | 核对互联网和提供方错误；可选无底图查看已有研究数据。NASA 指定日可能有云或内容不可用。 |
| 地图空白但表有数据 | 检查图层勾选、位置、绑定实体和数据覆盖；无几何不等于结果文件丢失。 |
| 任务一直等待 | 记录任务 ID、状态、时间，由维护人员检查队列与执行服务；不要重复提交相同计算。 |
| 任务失败 | 打开详情保存错误码、消息、追踪编号及版本；先解决原因再按允许的方式重试。 |
| 成功却没有可行优化解 | 任务成功是报告发布；看优化状态和约束表，不把无解改成零分配。 |
| 科研成功但 B/C 无效／阻塞 | 看逐项候选、诊断及来源；报告生成不保证模型候选有效。 |
| 数字显示 null／未知／未观测 | 查看缺测政策与来源；这些状态都不能自动填 0。 |
| 直接刷新带 .tif 等标识的详情 404 | 本机最新启动已加载修复。若旧部署仍报错，先打开首页从目录进入，并联系维护人员更新服务。 |
| 本机地址打不开 | 联系维护人员检查服务；运行步骤见[运行文档](web-runtime.md)。 |

提交问题时提供：页面名称、当前项目、资源／任务编号、版本、操作顺序、错误消息与时间；不要提供密码、令牌或私密连接串。

当前仍待补齐：人工修订观测、完整科研错误注入／消融／性能与统一报告、跨 CRS 守恒适配、非内置运行审批、部分任务诊断／缓存／保留清理、完整部署及最终门禁。可选 GeoAI API 对接也不是默认已可用功能。最新状态以[验收报告](acceptance-report.md)和[研发状态](STATE.md)为准。

## 23. data_quan 真实业务资料与模型

顶栏选择“data_quan 真实业务”。数据目录现有40个原始影像资产；它们与旧演示项目分开，不需要再次上传。名称保留原文件相对路径，版本1和完整SHA用于追溯；原目录未改写。

**查看资料**：在“数据目录”搜索TN或zhusanjiao，打开资产工作区。点击“读取实际文件预览”查看实际像元；“下载此版本原始文件”下载完整原文件。原始NoData显示为空，不把0或负类别当缺失值。TN坐标异常可以登记和下载，但不得直接用于空间计算。

**导入新资料**：“导入真实影像”支持本机文件或已授权目录。选择本机文件时只选实际TIFF，填写名称、来源与许可，年份可留空；程序读取尺寸、坐标、网格、缺测值并验证完整字节。已授权目录中选择data-quan-business，再选择文件即可。TIFF单文件上限2GiB，超限会明确失败，不静默裁剪。

**准备模型输入**：点“准备模型输入”，在列表中逐项“选择”需要联合分析的影像，最多8个变量。每项填写一个不重复的变量名称、真实数值单位与波段；珠三角四个距离字段的单位已由用户确认为m，GPNP指标含义不能由缩写猜测。移除只移除当前表单选择，不删除资产。四个珠三角影像同网格可以合并；不同网格会被拒绝，需要先确定科学对齐方案。

“全部共同有效像元”适合共同有效量不超过10000的资料；更大的资料可明确选择“随机样本”，填写4至10000的数量上限和固定种子。系统仍扫描完整影像并记录总数、共同有效数和排除数；只把选中样本送入当前统计模型。勾选标准化才在模型执行时按所选样本的均值和标准差处理。回归必须选择响应变量，未选择则准备聚类输入。统计时期与时间支持是科学声明，不能拿文件创建日期代替；可以留空登记，正式运行预检会要求补齐。点“生成可用于模型的输入资产”后得到可下载的受管资产，不需要填写矩阵JSON。

**模型中心**：两套已提供源码的运行包已登记并经管理员审批：PPCI投影寻踪聚类、pprRFA投影寻踪回归。审批表示固定实现的技术运行资格，不代表适用于任意科研结论。新项目需在“新增或导入模型”中登记，再由项目管理员批准运行适配器；普通成员不能自行取得审批权限。

**工作流与结果**：在工作流中选择固定模型版本、绑定准备资产的frame输入，设置聚类数或回归项数及种子，选取已定义场景，先“科学预检”，通过后“提交运行”。在运行详情等待成功，再“查看不可变结果”。结果表每页20行，按原始像元行列号追溯；地图显示真实观测位置。聚类编号没有好坏次序，回归拟合并非独立验证；样本结果不是全图成果。顶部“下载完整结果”保存全部观测、输出与运行来源。

**综合评价新增接入**：研发版已支持将上述栅格观测直接选作评价输入，无需另写indicator_frame。指标体系必须选择“网格”支持，并明确公式、源变量名称、方向、参考上下界及权重。采用原始数值进行公式计算，不沿用投影模型标准化指令。该增量已通过相关测试并于本次授权维护加载；真实浏览器已核对400条实际栅格观测的单位转换、行号、位置和样本范围；完整业务评价尚未验收。
