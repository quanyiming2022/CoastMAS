# CoastMAS V3 整改路线（审计交付，不在本轮实施）

顺序依赖以最新用户裁决为准：V3中心不增删合并；修复现有正确算法/资产/队列之上的断点。无需重做总体方案。每项实现同时交付UI→真实API→事务/权限→worker→实际产物，并按独立commit提交。

共同完成条件：同一构建、确定的原始/工程输入、请求和持久化、实际数值/产物与负例、桌面截图；失败/未跑不得升级状态。工程未实现不能写成等待用户。原件只读，科学歧义只阻断相应运算。生产替换另行授权。

Wave表示问题优先级，不是不可交叉的施工顺序：Wave 0的Planning编译依赖先补诊断/候选契约与SolverRegistry最小基础；先交付依赖再闭合编译，不能跳过科学前置。
