# 数据工作台

数据目录提供上传入口，详情页进入版本管理与实际文件预览。支持现有检查器的 GeoTIFF/COG、GeoJSON/Shapefile ZIP/GeoPackage、CSV、NetCDF、JSON。上传上限 64 MiB；服务端隔离进程读取内容、计算 SHA-256 并存入项目对象空间。来源、许可证及科学变量需要明确声明，未知范围或时期保持 null。

修订保留文件地址、摘要和大小，并撤销先前的质量验证；重新检查产生新版本。历史表单只读，可预览和下载原始字节。归档保留历史及文件，被引用数据由服务端阻止归档。预览是有界样本，文件结构检查不等于科学适用性审批。
