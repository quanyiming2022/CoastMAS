# 模型目录与匹配

模型文档采用 ModelSpec，JSON 与 YAML 导入均拒绝重复键，YAML 拒绝别名、锚点、对象构造与过深结构。文档及静态源码有大小上限。运行配置中的密钥必须由服务端引用，不能内嵌上传。

导入、复制与启用状态变化不能建立科学验证或执行授权。导入声称已验证的文档会回到 UNVALIDATED / NOT_EXECUTABLE；可信运行时注册与验证证据必须单独建立，当前审批界面尚未交付。

静态拆解提取 Python 函数、类方法、调用依赖、CLI 选项和声明式步骤。输出必须人工复核，不执行上传源码，也不把黑箱内部结构当作已知事实。

项目内检索支持名称字面量、能力、类型、启用状态和分页。历史版本不可修改。归档保留历史，并在事务锁内拒绝已有工作流或任务引用的资源。版本更新同步目录名称和运行启用状态。

`POST /api/v1/models/match` 使用授权项目内的服务端模型、数据和指定场景版本，重新进行科学预检。缺能力、输入、语义、单位、尺度、几何、CRS、参数或验证状态的候选不会进入排序，拒绝原因随结果返回。多个相关资产逐一检查，优先选择转换较少的兼容资产，平分时按资产标识与版本稳定排序。

排序分量是检索启发式，不是科学指标。能力和尺度在硬检查通过后记 1；数据可用度为已绑定必选输入比例；验证证据分量表示是否记录指标，不替代指标审查；耗时分量为 `1/(1+seconds)`，无实测耗时记 null；用户偏好在 0–1 内。加权和除以所有配置权重总和，缺失分量贡献 0，不能因缺失证据获得更高分。权重非负且总和大于 0。当前 HTTP 接口不接收未经验证的耗时估计。

匹配返回单模型候选片段，不表示完整场景或多节点规划已经通过。项目匹配读取上限 500 个当前模型/数据资源，超过则显式报错，不静默截断候选。
