# 结果中心与对照

结果中心按项目分页，每页50份不可变产物。选择两份结果进入对照页；更换项目会清空选择。左右两侧分别经过结果接口权限与对象存储 SHA 校验，显示原始地图、统计图表、工作流/场景版本、时间范围、输入指纹及下载入口，不覆盖原产物。

管理指标按计算节点、输出端口、科学变量、管理单元和指标名对齐。零值保持零，缺项保持缺项，单位缺失或不同明确显示，不做隐式单位转换。同一管理标识不保证两个项目或历史版本使用相同边界，因此仍展示两次运行各自的来源；原值并列不自动宣称科学可比或作因果推断。科学变化与年趋势来自相应评价模型的验证输出。

新运行保存 result_entity_geometries：只含已绑定的精确实体快照，显式转换到 WGS84，按实体/版本去重。不存在的版本或管理标识矛盾拒绝生成；未绑定结果不伪造几何。结果表“定位”与地图实体点击双向联动；原始 CRS 和几何仍保留在 geographic_entities 中。历史产物未补写此字段，继续可下载与追溯。

评价结果显示单期分数/等级或多期折线，支持管理单元和年份选择及完整时间序列表。非等间隔年份采用数值横轴，未知年份明确未声明，不能推断成当前年份；分数、等级和年份必须对齐，否则显示错误。显示和下载保留实际浮点值，测试按12位小数误差验证金标准，不靠改写计算值消除浮点尾差。
