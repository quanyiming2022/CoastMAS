# 协同方案与人工审核

入口为应用侧栏「协同方案」。本模块记录参与者立场、真实结果引用和数值约束，不把自动比较或人工审核当作政策决定。

## 操作与科学含义

选择项目后新建方案，选择可访问的固定场景版本，填写依据、目标标识/名称/非负相对权重和硬约束。目标权重总和必须有限且大于零；系统不把多方权重合成为自动政策。约束填写指标标识、明确单位及至少一个边界，零是有效边界。未知单位、反向区间、重复标识及非有限数值被拒绝。

方案可引用本项目、相同场景版本的实际成功运行结果。当前界面在结果中心获取结果编号后填入方案；服务端核验，不能用任意文字制造成功结果。PUBLIC 无权添加私有运行证据；公开方案中的结果引用不自动授予结果文件读取权限。

保存追加不可变版本。作者可以修订自己的方案；修改后回到草稿，清除旧审核记录，并撤回公开。提交后由另一位 MANAGER/ADMIN 记录「已人工审核」或「退回修订」及理由。即使全局管理员也不能自行审核自己创作的方案。审核人、时间和作者身份由服务端写入。旧版本及审核历史保持不变。

勾选目录中的固定版本，或在详情中与上一版本比较。系统展示场景、依据、目标权重、结果引用，并按同一指标标识检查区间交集。兼容单位先换算，不兼容单位明确报告 UNIT_MISMATCH，无法有限换算报告 UNIT_CONVERSION_FAILED，下界大于上界报告 EMPTY_INTERVAL。每个区间保留方案、版本和约束来源。目标高分不能抵消硬约束；没有发现区间冲突不代表完整政策可行性。不同场景、时期和范围必须结合具体条件解释。

意见记录绑定指定方案版本，不能编辑覆盖；历史方案可以继续追加意见。相同作者/方案/幂等键的重试返回原记录，修改内容或目标版本后复用旧键返回冲突。方案更新不会移动原版本意见。

## 统一权限与公开

沿用项目 Membership 和全局管理员身份，单一权限真源。RESEARCHER、MANAGER、ADMIN 和 PUBLIC 可以参与协同；VIEWER 只读。PUBLIC 只能查看已公开方案和自己的方案，并从已公开场景创建方案，不能因此获得通用数据、模型、工作流或运行的写权限。成员被撤销或停用后即时拒绝。

管理员可通过既有成员管理接口授予 PUBLIC。MANAGER/ADMIN 可显式调用 `PUT /api/v1/collaboration/scenes/{id}/publication`，携带 `expected_version` 和 `published`，公开场景；方案的同类接口为 `/api/v1/proposals/{id}/publication`，公开前需独立人工审核，界面也提供公开/撤回按钮。公开操作有审计记录。公开范围是该资源的历史版本，绝不递归公开引用的数据、实体或结果文件；新场景/方案修订撤回整个资源公开状态，重新发布需明确操作。

`GET /api/v1/collaboration/scenes` 提供按权限过滤的分页选择；公众不借普通场景目录获取私有对象。方案目录也是先过滤再分页。PUBLIC 的意见读取受父方案的当前可见权限控制，撤回公开后不能通过评论接口绕过。
