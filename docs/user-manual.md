# CoastMAS 用户使用说明书

逐页字段、按钮、表格列义及完整操作示例，请阅读[详细操作版](user-manual-detailed.md)。

适用版本：2026-09-21 本机研发版（UI/NAV 更新后）。系统已有可用功能，但**全范围统一验收尚未完成**；本文描述现有操作，不代表全部研发完成。

## 1. 登录与基本操作

1. 打开 <http://127.0.0.1:58000>，输入管理员分配的邮箱和密码。本机地址只适用于运行系统的电脑。
2. 登录后，先在顶部选择项目。看不到项目时，请管理员检查成员权限和项目是否归档。
3. 左侧四个业务分组可独立展开、折叠；系统记住分组偏好。进入详情页时自动展开所属组，当前入口有高亮标识。
4. 手机点击菜单按钮打开导航，选择入口后自动关闭；也可按 Esc 关闭。桌面账号与退出登录位于侧栏底部。
5. 表单修改后按页面按钮保存。折叠菜单不会清空表单，但离开未保存页面前应先保存。

账号与密码不在公开文档中提供。仅系统管理员可见“系统管理”；项目内操作还取决于成员角色。不要通过隐藏按钮判断是否已获得授权。

## 2. 首次使用：查看三个真实影像演示

在顶部选择 **“中国典型海岸真实影像演示”**，进入“场景与数据 → 场景空间”。

| 场景 | 影像日期 | 演示内容 |
|---|---|---|
| 黄河口 | 2025-09-25 | Sentinel-2 真彩色影像及 NDVI 植被指数 |
| 胶州湾 | 2025-10-27 | Sentinel-2 真彩色影像及 NDWI 水体相关指数 |
| 长江口 | 2024-09-01、2025-09-06 | 两期影像与后期减前期的 NDVI 变化 |

建议操作顺序：

1. 打开场景详情，再进入“场景工作台”；查看研究范围、采集日期、数据来源和图层。
2. 调整图层透明度；长江口场景可切换两期影像。
3. 需要背景参照时，在地图底图控件选择 **OpenStreetMap** 或 **NASA GIBS**；NASA 可选择日期。默认不加载互联网底图，联网失败会显示错误。
4. 首次浏览可直接去“运行与成果 → 结果中心”，打开已有成功结果，查看地图、数值、统计与来源。
5. 需要重新计算时，在已保存场景中选择对应工作流版本，执行“科学预检”，通过后“提交运行”；到“运行中心”跟踪任务，成功后打开结果。

这些演示使用公开影像的局部研究窗口，不代表整个海岸区域。底图只供显示，不参与计算；NDWI 不等于经过验证的水体分类，两期变化也不证明长期趋势或因果。详细来源、许可证和质量筛选见[真实影像说明](real-imagery-demos.md)。

## 3. 菜单与常用操作

### 场景与数据

| 入口 | 操作 |
|---|---|
| 项目概览 | 查看当前项目概况，从已有资源进入后续操作。 |
| 场景空间 | 新建或打开场景，绘制研究范围或上传 WGS84 GeoJSON 面，填写目标、时期、情景条件，选择实体和数据的明确版本；检查覆盖后保存。 |
| 数据目录 | 搜索、筛选、上传、预览、下载数据，修订元数据并重新检查质量；查看不可变历史版本。“数据来源”入口用于已有连接器的登记与导入。 |
| 地理实体 | 录入名称、类型、坐标系、有效期，上传单个 GeoJSON Geometry/Feature；查看地图或修订版本。管理单元标识与实体标识必须区分。 |
| 时间适配 | 选择基础场景，填写来源、变量、单位、方法、缺测策略及实际观测；保存生成工作流，再预检和运行。 |

数据上传支持当前检查器可读取的 GeoTIFF/COG、GeoJSON、Shapefile ZIP、GeoPackage、CSV、NetCDF 和 JSON，单文件上限 64 MiB。地理实体导入上限 8 MB，不能把多个实体的 FeatureCollection 当作单个实体上传。文件检查通过不代表科学适用性已获批准。外部数据源受管理员配置限制。

场景中的空间覆盖百分比是数据范围与研究范围的交集比例，**不是有效像元比例或无云比例**。修改场景后须保存，才能按新版本运行。

时间适配方法：

| 方法 | 用法 |
|---|---|
| 最近观测 | 取范围内最近的点观测；等距时取较早观测。 |
| 线性插值 | 仅在相邻有效观测之间插值，不外推、不用于类别。 |
| 时长加权平均 | 对完整覆盖目标窗口的区间平均值，按实际持续时间加权。 |
| 累计 | 将完整分割目标窗口的区间累计量相加。 |
| 最小值／最大值 | 返回所选观测的极值，不推断未观测期间的极值。 |

时间须带时区，例如 `2025-09-25T03:01:20Z`。缺测留空；真实零值填 `0`。区间空档、重叠、非法单位或不适用方法会阻止提交，不能通过补零消除问题。详见[时间适配](temporal-adaptation.md)。

### 模型与编排

| 入口 | 操作 |
|---|---|
| 智能编排（原“智能规划”） | 选择场景，输入完整目标；查看任务拆解、候选模型及缺失条件。有多个兼容数据时明确选择版本，再生成方案；审阅并保存工作流。 |
| 工作流 | 新建、编辑或另存副本；添加模型、连接输入输出、填写参数、绑定数据版本、选择发布输出；校验草稿后保存。 |
| 模型中心 | 搜索模型，查看契约与版本；按权限导入 JSON/YAML、修订、复制、导出及启停。已有“模型拆解”入口用于分析组件，不直接执行上传源码。 |
| 知识图谱 | 选择中心节点、邻域深度与关系类型；查看模型、变量、数据和工作流的关系，点击来源进入对应资源。 |

智能编排支持已有规则模板，例如“可持续性评价：等权综合评价”；必须具有满足目标的模型、数据和场景条件。未知目标不会仅凭关键词保证成功。使用配置的模型提供方需要明确允许；本机 Qwen 的候选同样必须经过科学检查。普通确定性工作流计算无需调用 LLM。

**保存草稿、模型启用、图谱存在连接，都不等于可以执行。** 运行前仍检查单位、坐标系、网格、时间、基准、数据版本及可信运行资格。修改输入后应重新预检。

### 运行与成果

1. 在场景、工作流或专用业务记录页面选择固定版本，执行“科学预检”。
2. 发现错误时，按诊断修正数据或配置；不要反复提交相同错误输入。
3. 预检通过后提交运行，在“运行中心”查看排队、执行、成功、失败或取消状态；取消及重试以页面实际可用操作为准。
4. 成功后打开不可变结果，查看地图、表格、图表、科学输出和运行清单；通过下载入口保留完整结果与来源。
5. 在“结果中心”选择两份结果进行对照。比较前核对变量、单位、研究范围、时期和版本；并排展示不自动证明科学可比。

修改模型、数据或场景会产生新版本，不覆盖历史结果。旧结果无法定位到实体时，应核查实体绑定，不要把没有几何的结果当作地图已成功定位。

### 评价与协同

**综合评价（原“评价中心”）**：新建指标体系 → 填写指标、公式输入列、单位、方向、固定归一化范围和权重 → 选择已验证的观测文件 → 准备评价数据 → 生成评价方案 → 保存工作流或评价记录 → 预检运行 → 查看分数、等级及多期变化。各时期须使用可比较的边界和权重规则，不能为了分数好看单独改变归一化范围。

**空间优化**：新建配置 → 选择基础场景 → 填写候选单元、收益、成本、面积、生态成本、风险、单位与科学依据 → 设置预算及硬约束 → 保存、预检、运行。结果须区分“最优”“可行但未证明最优”“不可行”和“达到时间限制”。无可行解不等于所有单元都未选。页面中的“载入合成示范”仅用于明确标记的验证，不是真实影像推导的管理资料，不应混入正式研究数据。

**协同方案**：新建方案 → 选择场景版本 → 填写依据、目标及硬约束 → 按需引用同一场景的真实成功结果 → 保存或提交审核。另一位具有管理权限的用户审核，作者不能自行审核。修订会产生新版本并撤销旧审核、公开状态。目录勾选固定版本后可比较或清除选择；意见绑定指定版本。公开方案不自动公开所引用的私有结果文件。

### 科研验证（原“科研评估”）

选择场景、固定模型和数据、输入目标并加入样例，选择实验组和重复次数；B/C 组需允许使用提供方。

- A：规则规划；B：配置的模型提供方规划；C：增加知识图谱连接证据的提供方规划。
- 本机真实模型标为 `LOCAL`，云端为 `EXTERNAL`，测试模拟为 `MOCK`，回放为 `REPLAY`；不能混为真实实验。
- 结果页显示冻结输入、候选、诊断、统计分母和报告下载。科研任务检验规划候选，不执行其中的科学模型。
- 人工修订次数没有真实记录时显示“未观测”；未配置提供方可能显示“阻塞”。报告生成成功不代表候选有效，也不证明某种方法更优。

### 系统管理与退出

管理员可管理账号启停、密码重置、管理员身份、项目成员、项目归档及审计记录。密码重置会撤销旧登录会话；系统保护最后一个有效管理员。

项目归档只隐藏常规工作区入口，保留历史，也不撤销成员权限；需要停止访问时，应调整成员权限或停用账号。恢复项目在管理界面操作。完成工作后使用侧栏底部“退出登录”。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 看不到菜单或不能保存 | 检查当前账号、项目和角色；联系管理员，不要改用其他项目绕过权限。 |
| 列表为空 | 先确认项目和筛选条件。真实无数据与请求失败不同，错误信息不能视为空表。 |
| 在线底图不显示 | 检查互联网连接及服务错误；保留“无底图”继续查看已加载的研究数据。 |
| 预检失败 | 查看具体变量、单位、时间、坐标系、数据版本或运行资格诊断，修正后重新预检。 |
| 保存提示版本冲突 | 重新读取最新版本，比较修改后再保存；不要覆盖他人更改。 |
| 任务失败或长时间等待 | 查看运行详情并记录任务编号、错误信息和发生时间，交管理员检查执行服务；不要重复创建相同任务。 |
| 结果数值缺失 | 核查原始数据、质量掩膜与缺测策略；空值不能当成零。 |
| 直接刷新某个数据详情出现 404 | 本机最新启动已加载带 `.tif` 等后缀标识的页面分发修复；若旧部署仍报错，先从首页目录进入，并联系维护人员更新服务。 |
| 本机入口无法打开 | 联系维护人员检查服务；启动与配置见[运行说明](web-runtime.md)。 |

## 5. 当前使用边界

本版已有三个真实影像演示及上述业务入口；新增 UI/NAV 已完成隔离浏览器验证。全范围研发与统一验收仍未完成，人工修订观测、完整科研错误注入／消融／性能报告、跨坐标系守恒适配、非内置模型运行审批、完整部署及部分运行治理能力仍在补齐。

正式使用结果时，应同时保留输入来源、精确版本、运行清单和完整产物；“任务成功”只证明执行完成，不代替科学适用性判断或管理决策。最新状态以[验收报告](acceptance-report.md)和[研发状态](STATE.md)为准。
