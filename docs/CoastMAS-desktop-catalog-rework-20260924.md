# CoastMAS 桌面工作台、分类目录与全站管理返工指令

**日期：2026-09-24。性质：可单独交给 Codex 执行的本轮返工规格；不是已经完成的产品或测试报告。**

## 0. 本轮裁决与执行范围

本轮解决已经出现的具体问题：默认无文字窄导航、地图左侧塞入完整资料库、TIFF/CSV/工程记录无差别混排、任务/方法目录仍为长链接列表、系统管理仍是巨型常驻表单、搜索/选择/修改/删除没有全站统一落实。

本文件完整定义上述返工范围，不需要寻找旧任务书、历史聊天或外部任务编号。当前已经正确的上传、解析、科学计算、图层显示、权限和数据版本可以复用，不为本轮再次重建系统。

### 0.1 替换旧的布局约束

- **桌面科研操作优先。默认主菜单完整展开，宽224px，显示图标及完整中文。** 默认56px窄轨及“必须用折叠菜单保证地图占比”的约束取消。
- **本轮不建设手机业务版，不把390px手机适配作为交付目标。** 不允许为了手机复用而牺牲桌面的导航、表格、操作和内容密度。
- 保留电脑窗口伸缩、用户主动调整面板、浏览器缩放与键盘可访问性；不把“取消手机适配”写成全页面固定图片、CSS整体缩放或文字不可放大。
- 不承担旧页面、旧API、旧私有结构兼容。新版自己的深链接、前后退、权限、草稿和历史结果身份仍须正确。
- **所有业务目录一起整改，不能只改数据页。** 任务、数据、方法、模型、运行、成果、项目及用户管理均有本文件规定的列与适用操作。
- 原始资料、模型包、现有未提交工作不删除。现有记录的回收通过正常权限和用户明确动作执行，不按名称批量清理用户环境。

### 0.2 看得见的问题与尚待核实的原因

截图已经显示布局和入口不足，但不能据此判断是否修改了某份源代码、后台所有管理接口是否存在、服务是否运行了最新构建。

开始仅定向核对：当前58010的前后端构建、工作目录及相关页面；导航/布局/目录/表单共用组件；各页调用的目录及写入接口。明确区分未实现、未接通、未部署、权限或显示条件影响。

不要先归咎浏览器缓存，不重做全站泛化审计，不要求用户补交未提供的旧文档。定向核查后直接实施下述页面和服务端行为。

## 1. 桌面应用外壳

### 1.1 确定布局

| 区域 | 规格 | 行为 |
|---|---|---|
| 全局顶栏 | 48–52px高 | 品牌、唯一项目/工作空间、面包屑、运行通知、账号；不重复摆多套项目选择 |
| 主菜单 | 默认224px；可手动调208–248px | 图标18–20px，完整中文14–15px，菜单行40–44px，业务分组有标题和选中状态 |
| 左侧工作面板 | 查看模式260–300px | 仅当前工作区资料/图层和相关工具；不是完整项目资料库的多列表格 |
| 中央视区 | 使用剩余宽高 | 地图/表格/矩阵随窗口伸缩，优先保留可读控件；地图边界不改变分析AOI |
| 右侧详情 | 用户打开时约300–340px | 默认无对象时关闭；不足以并排时作为主动打开的覆盖面板，不自动把主菜单缩为图标 |
| 底部抽屉 | 收起28–32px，可主动展开 | 属性、统计、运行、问题；局部滚动 |

支持用户主动收起主菜单，但不得初次进入、刷新或窗口稍窄就只剩无字图标。用户选的布局按个人偏好保存，不写进科学任务配置。

在1366×768、1440×900、1920×1080的CSS视口下核对桌面布局。1440及1366宽度下，主菜单展开、左面板打开、右详情默认收起；1920下可由用户同时打开左右面板。视区不够时提供“收起资料”“地图专注”“关闭详情”这些明确操作，不缩小全局字体硬塞，不隐藏需要的业务入口。

主工作区局部滚动，表格可横向滚动；一般表单保持正常阅读与键盘导航。浏览器200%缩放时允许重排或滚动，不能用overflow裁掉交互元素。此为桌面可用性，不是建设手机产品。

### 1.2 菜单业务组织

| 分组 | 入口 |
|---|---|
| 研究项目 | 项目概览、任务管理、研究工作台 |
| 数据准备 | 数据资源、年鉴与统计空间化、空间处理工具 |
| 指标与评价 | 指标生产、指标标准化、权重与综合评价 |
| 模型与方法 | 模型与算法、指标方法方案、标准与字典 |
| 成果与验证 | 运行记录、成果管理、科研验证、方案协同 |
| 系统管理 | 项目与成员、用户账号、已授权数据源、回收站、审计 |

可使用菜单组折叠，当前组和当前位置可见。模型上传位于模型与算法的明确入口，不用方法定义表单替代。未经批准/尚未实现的能力如实标记，不能空按钮冒充实现；原约定的业务能力不因菜单调整删减。

系统级账号管理明确系统范围；项目成员明确当前项目范围。系统管理员身份不自动扩大对其他项目业务资料的读取权。

## 2. 分清“资料库管理”和“当前地图工作区”

### 2.1 资料库管理模式

用于查找、分类、批选、修改、删除和恢复。主体必须是宽表格，不是地图旁边约220px的多列表。

布局：全局主菜单 → 资料分类/集合树（约200px，可主动收起）→ 主目录表。详情按需从右侧打开；地图作为当前对象的预览标签或切换入口，管理模式不强制占据大半页面。

最上方显示当前集合/筛选摘要和真实数量，工具条提供搜索、类型/状态/阶段筛选、导入、刷新、列配置与密度。表头固定，分页固定在目录底部。

### 2.2 当前工作区模式

用于查看和分析。左侧仅列已经加入当前查看工作区的数据及其图层；可分“图层”“已用资料”“工具”标签。点击“从资料库添加”打开完整目录选择器。

- TIFF和有几何的矢量可作为地图图层。
- 普通CSV/XLSX在已用资料中作为表格打开，不假装地图层，不要求为看表补几何。
- 有可靠坐标或行政关联的表格，可生成有来源的地理显示层，原表身份仍保留。
- 大文件的波段/时片/包内逻辑层在资产下展开；批量选择资产与勾选图层显隐不能共用一个含糊复选框。
- 当前显示的资料被目录筛选排除时，在工作区仍显示活动层名称和“当前筛选外”提示；提供返回所属集合/清除过滤，不让左侧所选CSV与右侧活动TIFF失去解释。
- 进入分析只带入用户已确定的输入引用。资料行单击、查看图层、地图平移不静默改变分析输入。

**同一资料库可保存不同格式，但管理必须分类，地图列表不能变成所有文件按时间混排的缩小版资料库。**

## 3. 多类型资料的分类设计

分类依据来自真实解析和受控元数据，不单靠文件名。

### 3.1 三个正交维度

| 维度 | 值与行为 |
|---|---|
| 技术数据类型 | 栅格、矢量、表格、文档、复合容器/其他；再显示实际格式和版本 |
| 业务角色/阶段 | 原始资料、年鉴统计、处理过程、空间化结果、原值指标、标准化指标、综合/贡献、质量验证 |
| 用途/来源性质 | 真实业务、工程验证、示例、尚未核定；必须有来源或授权分类依据 |

技术类型只读或经重新解析纠正；用户不能改一个标签就把CSV变成栅格。业务角色可按权限编辑并记录依据；名字带statement/history/test只作为查找线索，不能自动认定为测试资料或直接删除。

### 3.2 文件和逻辑数据集规则

| 输入 | 目录呈现 | 查看/分析入口 |
|---|---|---|
| GeoTIFF/COG | 栅格资产，保留band/定位/mask/实际格式信息 | 自动地图、波段/值查询；未知科学单位不阻断可靠原值显示 |
| NetCDF等多维容器 | 资产＋变量/时片分组，支持状态明确 | 有可靠定位和受支持日历时进入相应视图；不把全部变量混成一层 |
| GeoPackage/GeoJSON | 容器/资产＋真实图层、空间表或非空间表 | 几何图层上图，非空间表进入表视图；不静默仅取第一层 |
| Shapefile配套文件 | 一个逻辑数据集＋文件部件 | .shp/.dbf/.prj等不当成几个互不相干的资料 |
| CSV/TSV/XLSX | 表格；普通表、年鉴、地理表按实际映射区分 | 普通表默认查看记录；可信坐标/行政键可建立地理绑定 |
| CSVW及副车 | 表格＋其元数据关系 | 不把元数据说明单独混入当前地图图层 |
| PDF/HTML/文本年鉴 | 原始文档＋提取统计表的派生关系 | 原文/原页和统计表对照；没有空间关系不强造地图 |
| 模型/算法包 | 进入模型与算法目录；可保留原包资产引用 | 静态检查、受控验证、版本发布；不放在地图图层组 |

同一显示名不必然是重复记录；资产ID、版本、hash、来源和许可共同展示于详情。发现重复只给有权限的复用建议，不自动合并或删历史。

### 3.3 分类查询必须真实

类别和阶段显示数量来自当前授权数据的聚合。分类切换使用服务端条件并重置页码，作用域在工具条明示。查询响应中保留分类分母和范围；没有权限不泄露其他项目文件是否存在。

将资料从某分类改到另一业务阶段后，重新查询、刷新和重登都要一致；图层引用和源文件不因分类改变而复制或丢失。

## 4. 全站共用目录组件，而不是逐页手工列表

### 4.1 固定工具栏和表行为

工具条：标题/数量、搜索（280–360px）、最常用2–3项筛选、更多筛选、新建/导入、刷新/列配置。选择行后出现批量工具条，明确选择数量和范围。

- 正文及目录字14px，表头14px/600；辅助文字12–13px；不缩成难读小字。
- 默认行高40px，紧凑36px为用户选择。说明放详情，不每行换三四行。
- 文件名主行省略并可查看/复制完整值；格式、大小、版本分列，数字右对齐。
- 表头选择框具有未选/部分选/本页全选三态。
- 简单只读表用原生语义表格；编辑网格按真实键盘行为实现，不能只加role。
- 操作文字简短：“编辑”“停用”“重置密码”“更多”。完整账号名称在所在行和确认界面，不在每个按钮重复。
- 不把红色删除当默认主按钮；选择行、操作按钮、显隐开关互不触发行跳转。

### 4.2 搜索、分页与多选

搜索当前权限范围内全部匹配数据，不是仅过滤当前20条。处理中文输入法组合，清空恢复，Enter可立即查询。排序稳定并以ID作为次级键；旧请求晚到不能覆盖新查询。

提供每页25/50/100项（规模和能力按实现限制），显示实际匹配数量。没有精确总量时明确说明，不能伪填0或谎称“全部”。

全选须区分：

1. 全选本页。
2. 跨页已选明确对象。
3. 全选当前筛选结果：服务端生成固定选集/快照标识，显示实际数量，允许排除单项。

筛选变更后旧选择不能暗中变成新结果集；清除选择或明确保留旧选集。批量执行逐项复验权限、版本和依赖，部分失败逐条说明，成功项不伪回滚。

### 4.3 各目录必须交付的列与动作

| 目录 | 默认列 | 本轮实际操作 |
|---|---|---|
| 任务 | 选择、名称、类型、当前环节、最近运行、成果、更新时间、操作 | 新建、搜索/筛选、编辑草稿/名称、复制、分类、选择/全选、回收/恢复；运行中处理见第6节 |
| 数据 | 选择、名称、技术类型/格式、业务阶段、大小/规模、时空摘要、状态、更新时间 | 导入、查看/定位、加入任务、修改显示名/标签/声明、分类、选中/全选、回收/恢复、下载、引用 |
| 方法 | 选择、名称、业务用途、算法、指标数、版本、认可范围/状态、维护时间 | 使用、导入、克隆、编辑草稿/创建修订、搜索/筛选、批量分类/归档/回收/恢复 |
| 模型算法 | 选择、名称、用途、运行类型、固定版本、运行资格、验证时间 | 使用、上传新包/版本、查看验证、停用、搜索/筛选、适用回收/恢复 |
| 运行 | 选择、运行编号、任务、配置版本、类型/范围、状态、时间/耗时、操作 | 搜索、取消进行中作业、重试/新意图复跑、查看成果、终态回收；历史数值不可编辑 |
| 成果 | 选择、名称、来源运行、种类、范围/时期、显示状态、验证状态、时间 | 打开、对比、修改显示名/旁注、导出、查询引用、回收/恢复；不改历史科学数值 |
| 用户账号 | 选择、邮箱/名称、系统身份、状态、项目关联摘要、时间、操作 | 搜索、创建、编辑允许信息、启停、单独重置密码、适用回收；最后可用管理员保护 |
| 项目/成员 | 选择、名称/人员、状态/项目角色、更新时间、操作 | 搜索、创建/编辑、授权成员变更、归档/恢复/适用回收 |
| 审计 | 时间、操作者、对象、动作、状态 | 搜索/筛选/详情/授权导出；不提供伪造历史的编辑删除 |

这些是一个组件体系的不同对象配置，不是把所有对象统一成相同字段表。缺少对应后端列表或写入能力属于本轮工程任务，不能只把按钮灰掉宣称完成。

## 5. 三个仍然未专业化的页面必须一起修改

### 5.1 任务管理

默认进入任务表，不常驻“任务名称＋类型”巨型创建卡。标题行放新建任务，点击后打开约560–640px的对话框/侧栏。先选择真实任务用途或已认可方案，任务名称自动建议、可修改。

创建后进入对应业务工作区。草稿版本不充当当前业务阶段；最近运行和成果状态分别呈现。任务有实际运行后能从行内直接打开该运行或成果。

### 5.2 方法与模型

默认目录和“使用”操作，创建/导入/上传/克隆放工具栏。工程用途、业务用途和未核实用途有可见标识及筛选；不能只把免责声明放在每条长说明里。

编制方法时，一行一个指标，概念/单位/方向/评分/权重来源列化；点行查看或修订详情。不自动推断方向，不从文件名猜科学定义。已批准版本修订产生新版本，普通任务不重复编制方法。

模型包上传为独立入口，保留静态检查、授权隔离验证和固定版本发布；不执行不可信上传来“省步骤”。

### 5.3 系统管理

账号、项目、成员、审计分标签/子菜单。默认账号表及工具栏“创建账号”；默认项目表及“新建项目”。新建表单不与全部列表常驻堆叠。

新账号对话框约560px，邮箱约320–360px，密码输入提供安全显示切换；授权提升单独解释和后端校验。重置密码只在当前提交持有，不进草稿、日志或本机存储。批量启停可用；批量重置密码不当默认操作。

已存在的账号筛选和启停/重置能力可以复用，本轮不是假设全部没有，而是完善共用目录、可读操作、编辑和批选。禁止停用/删除最后一个可用系统管理员，禁止通过前端隐藏跳过后端授权。

## 6. 表单尺寸与编辑/删除语义

### 6.1 紧凑不等于全部压扁

| 场景 | 尺寸/组织 |
|---|---|
| 搜索 | 通常280–360px，避免占整屏一长条 |
| 名称、邮箱 | 通常280–360px；有需要再扩大，不自动填满1500px |
| 数值、年份、单位 | 120–180px，数字与单位有明确分隔 |
| 下拉选择 | 按内容180–280px；复杂资源用检索选择器 |
| 简单创建/重命名 | 560–640px对话框或窄抽屉 |
| 复杂业务编辑 | 640–800px详情抽屉或独立专业编辑区；按实际任务选择 |
| 指标/候选批量输入 | 主区表格，导入/映射优先，不堆几十组空框 |
| 说明 | 默认2–3行；可展开；已知方法说明放只读详情 |

按实际输入职责分组，同一行只放相关项。按钮采用内容宽度，禁止仅为填满网格而让“创建账号”横跨半屏。减少标题、卡片内边距和重复说明，不减少可读文字大小。

有可靠来源的值自动读/继承；缺项按当前操作要求展示。ID、格式、CRS、波段不能重新要求无意义手填。修改仅重验受影响项。

### 6.2 编辑、回收、恢复必须真的保存

- 显示名、备注、分类和标签可以轻编辑；revision/ETag或等效并发校验，接口成功后才显示已保存。
- 数据值、几何、单位或科学定义改变，生成可追溯的新数据/声明/方法版本，不覆盖原件或既有运行产物。
- “移出当前图层”“移出集合”“移出任务”只移除关系；“移入回收站”是记录回收；“永久清理”才涉及物理副本。界面命名不同。
- 正常回收一次明确确认，说明所选数量和影响；刷新和重登仍在回收站，支持恢复。不能只是前端删除数组元素。
- 运行中存在租约/依赖时逐项判断，提供取消/等待或保留关系的可行操作；DELETE不代替终止worker。
- 不同结果共用blob、有保留策略、被历史引用时不物理清理；不删除用户外部原目录。
- 账号与审计要保留行为主体与记录；停用账号不等于删除其研究证据。用户删除账号采用受控的停用/逻辑回收流程，界面明确解释。
- 删除前预检和执行时再次授权与版本检查；预检后新增依赖不能被旧确认绕过。
- 按真实来源整理工程资料，任何批量回收需正常用户操作；不能以“美化界面”为由清空真实项目。

## 7. 当前地图页面的具体调整

### 7.1 原始资料、质量检查、正式分析分开

原始栅格接入后自动显示。文件标题、活动变量、图例及点查固定到实际资产与版本，不从文件名判断它是距离、坡度类别或有效掩膜。

“生成有效覆盖”移到“空间工具 → 数据质量 → 有效覆盖”或当前图层更多菜单，不常驻为所有资料的唯一核心按钮。原件显示不以计算覆盖结果为前置；这项质量工具也不充当综合评价成果。

0/1文件可能是合法原始类别，也可能是派生mask；必须按真实类型、方法及元信息呈现，不因为图例0–1就断言算法错了。

### 7.2 收敛显示信息

一个紧凑上下文栏显示活动资料/结果名称、类型/状态和导出；一个地图工具栏控制定位、显隐、透明度、底图与图层。文件事实和科学说明放详情，不用两三层白色横栏重复占高。

右侧图层属性默认只显示关键摘要。NoData、有限值、显示样本、真实像元统计等用紧凑键值表与明确对象名称，长技术解释可展开。图例和色带来自实际数据，不把缺测、类别和连续量混同。

地图视角跨目录/任务继承个人视图状态；“定位本层”才主动fit。切换任务可按明确默认首次定位，已手动平移后不被后台请求反复重置。不同视角不单独视为投影错误，坐标正确性需实际源数据核对。

### 7.3 成果必须保留可视分析

已有空间分析真实产物默认在中央显示；地图、表格、权重、贡献和下载引用同一run。资料检查显示质量报告，无空间表格只给真实表/图，不伪造地图。

综合评价的数据整理、空间化、指标、标准化、权重、综合与验证流程继续存在。此次目录和外壳返工不要求重写算法，不允许以只交一个覆盖图替代完整综合结果。

## 8. 服务端和状态约束

共用CatalogQuery/CatalogSelection/RecordMutation能力，按对象配置权限和字段。以下是职责要求，不是声称现有接口已存在：

- 查询：project/scope、kind、format、stage、purpose、status、collection、keyword、sort、page/cursor；筛选字段白名单，服务端授权。
- 返回：records、pagination/count语义、facet_counts的作用域、允许操作及禁止原因、row revision。
- 选集：显式IDs或服务器固定selection_ref，冻结筛选与快照，必要时排除ID；不能靠浏览器传一个不受控“delete all”。
- 修改：只允许明确选择的字段；批量混合值不把空白当清空；并发冲突可重新加载/合并。
- 回收/恢复：预检→一次确认→逐项执行→返回成功/失败/未处理。界面同步刷新目录、详情、计数和已选对象。
- 视图：查询、排序、密度、列宽、活动图层、视口和面板状态按个人/项目保存；不是第二份科学数据真源。
- 目录、图层、点查、导出和缓存均校验访问；缓存命中不能绕过撤权。

前后端类型同源，共用目录组件与对象配置，不逐页复制临时实现。新结构不必兼容旧私有API；保留当前正确的科学校验和有效历史证据。
