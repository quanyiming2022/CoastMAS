# 场景工作台与覆盖检查

从场景目录“新建场景”，或场景详情“打开场景工作台”进入。地图支持缩放、平移、点击绘制 AOI、撤销顶点和取消绘制；至少三个不同顶点后闭合。上传接受 WGS 84 GeoJSON 的单个 Polygon、MultiPolygon 或 Feature，服务端进一步检查环闭合、拓扑、顶点预算与 CRS。地图优先聚焦当前 AOI，项目实体作为背景；未加载外部底图。

## 场景版本

填写管理目标、含时区的开始/结束时间、实体类型、情景条件、数据策略、质量要求与所需输出。字段组和列表用表单编辑，未指定的标量保留 null，数值 0 不被当成缺失。已有场景复制保留目标网格、垂向基准、人口分布假设等完整科学条件；新场景不会自动捏造这些条件。

实体和数据通过分页目录选择精确版本，SceneSpec 的 entity_references、data_references 每个标识只能对应一个版本。数据库用 ResourceDependency 复合外键记录场景版本引用，拒绝跨项目、无效版本、归档或停用对象。保存产生不可变版本，expected_version 防止覆盖并发修改；复制产生独立标识。历史版本可读取并与当前版本比较。

## 覆盖含义

`POST /api/v1/scene-drafts/inspect` 只检查，不保存、不运行。返回服务端加载的精确版本和派生 WGS 84 几何：

- 数据空间比例：目录声明的空间范围（或已验证栅格/矢量文件检查得到的实测范围）与 AOI 在 EPSG:6933 等面积投影中的相交面积比，方法标识 catalog_extent_equal_area_EPSG6933 或 inspected_extent_equal_area_EPSG6933，来源明确区分。**这不是有效像元比例，不证明 NoData、云量、观测误差或真实数据质量。**
- 数据时间覆盖：元数据必须覆盖完整请求时期；未知时间保持 null/UNKNOWN，不能自动算通过。
- 地理实体：几何须与 AOI 相交，实体类型须由场景声明，有效期须覆盖完整分析时期。实体行不提供虚构的面积覆盖比例。
- 未知/部分/范围外会明确显示。覆盖说明不替代工作流变量、单位、CRS、网格、NoData、基准和运行资格检查。

CRS 转换采用明确轴序、禁用 ballpark、不可用即拒绝。重投影前有界加密线段，保留 100000 顶点上限。当前等面积检查对跨日期变更线和南北纬 86°以外的 AOI 明确拒绝，不能当作这些区域已有科学方法支持。

## 从场景运行

修改草稿后必须保存才会显示运行操作。在固定场景版本下，选择工作流精确版本、执行真实预检、提交实际队列任务；提交复用幂等标识。一旦场景明确选择数据，工作流每个外部输入的精确版本都必须在所选集合中，否则 SCENE_DATA_SELECTION 阻断；不会在界面选一份、实际却运行另一份。未声明集合的旧场景仍采用工作流固有绑定。服务端在提交和 worker 执行/发布前重新检查选定实体、数据的权限及可用状态；停用实体的在途任务不得发布成功结果。产物保存所选地理实体完整快照，来源可复查。

新增的可选引用字段不改写旧版本。读取时先验证原始序列化摘要，再按同一契约规范化比较可选默认值；历史场景和重复样例初始化有专门回归测试。实体身份、管理单元身份和结果对象身份必须不同。当前实体快照已进入产物，完整“结果对象→地理实体→管理结果”绑定界面仍在研发，不能将快照等同于完成结果绑定。
