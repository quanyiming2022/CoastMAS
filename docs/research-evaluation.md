# 科研规划对照

科研规划与工作流计算是两种任务。科研任务调用规划器并检验候选，不运行候选中的科学模型；模型计算仍需保存工作流并通过统一预检。科研任务复用现有队列、租约、取消、当前权限复核和不可变成果发布。

## 实验方法

每组冻结相同的场景版本、模型版本、数据版本、目标文本及显式数据选择。A使用实际规则规划器；B向配置的提供方请求候选；C在相同目录和硬约束之外，增加实际知识图谱产生的模型连接证据。图谱连接只是契约上的候选关系，不是科学正确性证明。B/C均经相同科学核验统计有效性，非法候选保留，禁止执行。

每个提供方试验最多一次请求，不隐式修复、自动重试或偷换为规则结果。当前方法没有验证自由文本目标的全部语义正确性；输出必须满足明确的场景输出及机器可验证约束，解释仍需人工核查。人工修订次数没有真实记录时为null，界面显示未观测。

每个试验记录来源RULE、LOCAL、EXTERNAL、MOCK或REPLAY，分别统计，不混合。本机回环地址的真实提供方标记LOCAL；协议测试显式标记MOCK，不能计为真实模型科研结果。LOCAL的定义是所连接端点的位置，不凭此证明远端后端的运行架构。缺少云凭证的真实外部实验仍是BLOCKED。

## 分母、失败与缺测

总试验数保留阻塞与失败项；完成率分母为全部试验，有效率分母为实际完成评估的试验，并同时展示这两个分母。没有候选时有效性为false，约束违规率不把它当作已经审查的候选。提供方协议失败时有效性为null，状态FAILED；无提供方时BLOCKED。未知token、人工修订和延迟不补零。

实际调用数取自数据库已发送记录，不等于预留预算。token只取提供方返回值，不按字符估计，也不重复累加缓存或推理子项。重复任务投递复用已保存的试验记录；显式重试保持同一实验身份。已有一次请求预留但无法恢复结果时报告不可重放失败，不再自动发送第二次请求。

任务SUCCEEDED只表示报告已可靠生成；报告可能是部分完成或全部阻塞。科研成果质量标记RAW，不能因报告格式完整就宣称全部候选科学有效。

## 使用入口

在“科研评估”选择场景、固定候选模型/数据及目标，加入样例，选择A/B/C和重复数；B/C调用需勾选允许提供方。结果页分别显示任务状态与评估状态，提供冻结输入、逐项候选、诊断及JSON下载。

本机验证入口（要求已有归档验证项目和可用服务）：

```sh
.venv/bin/python scripts/run_research.py --provider --origin LOCAL --key local-qwen-frozen-planning-v1
```

同一键复用原任务，不重复请求；新的真实对照必须使用新的明确实验键。省略--provider会把B/C记为BLOCKED。不能修改原报告来制造更好的实验结果。
