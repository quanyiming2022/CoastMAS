# 模型中心

模型目录支持服务端跨页名称/标识、能力、模型类型和启用状态检索。新增/导入入口提供 JSON/YAML 导入、科学字段表单、明确单位和尺度；零值保留，缺失字段不补造科学参数。

版本管理可保存修订、查看不可变历史、导出指定版本 JSON/YAML、复制最新版本、启用/停用和归档。历史表单只读；服务端保护已引用模型。科学元数据修改会撤销验证和执行资格，启用按钮不代表运行审批。

静态拆解支持 Python、CLI、声明组件、已有流程和黑箱。Python 使用服务端 AST 分析，不导入或执行源文件；展示实际组件依赖、阶段、输入输出和警告。CLI 每行一个 argv 参数，保留空格及零字符串。黑箱保留原子组件，不推断内部科学机制。声明组件必须无环且引用有效。输入变更隐藏旧候选；文件内容不能覆盖界面所选名称和方式。候选可以下载，始终需要审核且不可直接执行。
